## 판정 기준 (승윤님 원칙, 2026-09-04)
실측으로 고칠 수 있는 것 → 모델 식별 / 실제로 변하는 것 → DR(범위가 커져야만 transfer 되면 nominal 의심) / 센서·통신 → noise+delay / 마지막 → 실물.
보상 복잡화 금지, 학습 reward 만 보지 않고 결정론 명목 평가로 생존율·낙상 방향·pitch/roll RMS·좌우 착지 비대칭·joint velocity·peak torque·
torque saturation·foot slip·action smoothness 를 함께 기록. 회귀 금지: E_smth·에너지 15% 이상 악화면 승격 불가.

# W3S3e — 재출발을 학습 분포에 넣는 단일 변경 (사전 등록 v1, 2026-10-07 21:28, claude2, **학습 전**)

> 상태: 학습·평가 전에 기준을 고정한다. 이 문서 커밋 뒤 기준을 바꾸려면 v2 로 새로 적는다. 승격은 사용자 결정. 시뮬 수치는 실물 확률이 아니다.

## 1. 근거(측정 사실 — `TRANSITION_W3KE.md` §5.11b·§5.11e, 배포 코드 폐루프)
- 합성 구조의 왕복 대본(X7)이 48 s 낙상 7.4 % 로 기준(≤ 5 %)에 미달했다. 낙상은 첫 걷기에서 0 / 203, 둘째 걷기 0.3 %, 셋째 이후 2.3 %(X7b).
- 걷기 한 번(4 s)의 요 변화 중앙이 왕복마다 커진다: 4.2 → 8.1 → 11.2 → 12.6 → 13.5°(고리 끔). 헤딩 고리를 켜면 다섯째 걷기에서 env 의 3 분의 1 이 오차 15° 고장에 걸린다(HD1 seed 1 관찰).
- 걷기 사이를 KE 서기 대신 W3 STAND 로 이어도 요 변화 증가는 같다(X7c C1 seed 1: 3.9 → 14.1°, 대조 3.9 → 13.5°) — KE 를 끼운 것이 원인이 아니다.
- **학습 분포의 공백(코드 사실)**: W3S3d 는 에피소드 20 s·명령 리샘플 8–12 s 라 에피소드당 명령 구간이 2 개다. "걷기 → 서기 → 다시 걷기"는 구간이 3 개 있어야 나오므로 학습에 사실상 없었다.
  서기에서 걷기 시작은 초기 자세(대칭)에서만, 걷다 서기는 에피소드 끝에서만 겪었다.
- 미확정: 자세 되돌리기 개입(X7d)·부드러운 정지/시작(X7c C2·C3)의 결과. **학습 시작 조건**: X7d 가 "물리 자세가 원인"을 기각하지 않을 것(기각되면 이 설계를 보류하고 제어기 상태 쪽을 본다). C2·C3 가 구조만으로 해결하더라도 이 학습은 대조로 진행할 수 있다.

## 2. 가설·단일 변경
- 가설: W3 가 자기 정지 자세에서 다시 걷는 상황을 학습하면, 둘째 이후 걷기의 요 변화 증가와 낙상이 줄어든다.
- 변경(하나): 명령 리샘플 간격 8–12 s → **4–6 s**(`Biped12-HangStand-W3S3e-v0` = W3S3d + `commands.base_velocity.resampling_time_range = (4.0, 6.0)`). 에피소드 20 s 에 구간 3–5 개.
  보상·관측·DR·커리큘럼·학습 지연 1–5·p_step 0.7·명령 범위는 W3S3d 와 같다(보상·추적기에 구간 길이 의존 없음 — `rl_walking/w3.py` 확인).
- 알려진 부작용 후보(사전 명시): 구간이 짧아져 한 명령을 따르는 시간이 줄어든다 → 속도 추종·회전 이득이 떨어질 수 있다(§4 회귀로 본다).

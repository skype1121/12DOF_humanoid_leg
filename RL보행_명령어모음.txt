■ 2. 학습 (헤드리스 — GUI 필요 없음, 1회 ~30분)

cd /home/ryu/humanoid_leg_test1

#  Biped12-Velocity-Flat-Stage3-v0 3단계 (실물12kg·배터리0~5kg·지연·후진) ★이식용

■ 7. 문제 해결
───────────────────────────────────────────────────────────────────
1) 데모 "is_homogeneous" 오류 → 씬 로드 중. 한 번 더 실행
2) "--resume True" 금지 → --resume (값 없이)
3) 학습이 순식간에 끝남/이상 → 로그에서 Traceback 검색
   (grep -i traceback <로그>; isaaclab.sh는 exit code 못 믿음)
4) 학습 크래시 "std >= 0" / NaN → 물리폭발. 이미 방어 3종 적용돼 있음
   (log-std, 솔버 강화, 험지 페널티 캡) — 재발 시 푸시·지형 난이도 낮출 것
5) GPU 사용량: nvidia-smi (학습 ~5GB, GUI ~3GB — 동시 가능)
6) ModuleNotFoundError: isaaclab → 반드시 isaaclab.sh -p 로 실행
7) 프로세스 정리는 pgrep으로 PID 확인 후 kill <PID> (pkill 패턴 금지)

## 케이블 현가 모델 — **0911 결과 전부 철회(모델 비활성 버그)**, 0912 재평가
**철회 사유(MEASURED, 0912)**: 0911 케이블 평가(v5_cable_nom 99.2 %, v5_cable_dr 14.8 %, v5_cable_nom_slow 99.2 %)는 케이블이 **한 번도 힘을 내지 않은** 결과였다. `hang_support_reset` 이 프리텐션 `d0 = r0·m·g/k` 와 `tmax = 1.5·m·g` 를 `st["mass"]` 를 채우기 **전에** 계산해 첫 에피소드에서 mass = 0 → tmax = 0 → 장력이 에피소드 내내 0 으로 클램프됐다(평가는 에피소드 1개). 발견 경로: 앵커 편심 0/±0.1/±0.2/+0.3 m 스윕이 피치·관절각까지 **비트 단위 동일**(Δ = 0.0) → 덤프에 `cbl_T` 를 기록하니 전 구간 0.00, `d0 = 0.0000`. 셀프테스트는 장력 식만 검사해 잡지 못했다 → 리셋 순서 수정 + 런타임 가드(d0·tmax > 0 아니면 중단) 추가(커밋 c631aec). 따라서 위 세 수치는 "지지 없이 ≤15 cm 높이에서 떨어뜨린 v5" 의 수치이며, 그로부터 끌어낸 결론("케이블 모델은 DR 에서 초반 동적 낙상만 만든다", "느린 방출 중 발목 추종오차 반대칭 = 케이블 효과")은 **모두 철회**한다. 시뮬↔실물 부류 비교표의 '시뮬 케이블 DR+푸시 낙상' 행도 같은 이유로 무효.
**길이제약 모델의 한계(MEASURED, 수정 후 8 env 진단)**: 수정 후 길이 모델은 로프 강성 k(1500~3000 N/m, **미측정 가정값**)와 스폰 낙하 기하에 결과가 지배된다 — 착지 후 몸이 8 cm 가라앉으면서 줄이 체중 이상(212 N > 173 N)으로 당겨 발이 뜨고, 방출 끝에도 16 N 이 남아 '지지 소멸'에 못 간다. 즉 k 를 모르는 채로는 판정 근거가 될 수 없다.

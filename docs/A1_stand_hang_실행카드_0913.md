## 1. 0912 와 달라지는 근거 (MEASURED / 계산)
1. **가드는 원인이 아니었다.** 5회 모두 가드 정지 0건(T1 리프트 가드 제외). 정책은 넘어지는 동안에도 살아 있었다. 가드는 바꾸지 않는다.
2. **정책은 느린 기울기(≤1 °/s·≤5°)에 반응하지 않았다**(롤 관절 목표 변화 ≤1.1°, 이득 0.11~0.13 °/°). 시뮬도 같다(램프 저항은 수동 강성 몫).
3. **부분지지에서 버틸 수 있는 외란 모멘트는 발 하중에 비례한다**(시뮬 홀드 천장 14.6~15 Nm @50 % 지지 = 접촉 한계). 지지가 남아 있는 시간이 길수록 작은 모멘트에도 넘어진다.
4. 구맵 영점 오차(힙 요 −7.5/−6.3° 등)는 제거됐다(재캡처). IMU 는 수평에서 lat +1.3° 를 낸다(장착 편향).

## 2. 현장 사전 확인 (0911 §3 에 추가)
- **영점 확인은 지그 자세에서**: 콘솔 `영점 확인 12/12`, 잔차 3° 안. 3° 밖이면 배수 보정 우선, 재캡처는 지그 자세에서만(승인).
- **오른발 뒤바깥 패드(right[3])·왼발 안쪽 2채널이 0 카운트인지** 손으로 눌러 확인(0912 지그 접지에서 0 = 죽은 채널 의심). 죽은 채널은 접촉 판정 감도만 낮춘다(오판은 안 만듦). 패드는 접촉 여부용이다.
- **줄 연직**: 착지 직전 로봇이 앵커 바로 아래에 있는지(다림추 또는 카메라 정면 뷰). 앵커 10 cm 오프셋 = 50 % 지지에서 약 6 Nm 롤 모멘트(천장 15 Nm 의 40 %).
- **카메라**: 발·줄·후크·윈치 손이 한 화면에. 윈치 이벤트 버튼(▶ 방출 시작 / ⏸ 정지 / ↥ 재인장 / ✓ 느슨)을 반드시 누른다 — 0912 는 5회 모두 미기록이라 판정에 구멍.
- 매달려 정지했을 때 콘솔 lat 이 +1.3 ±1° 인지(좌우 정렬; 0912 T5 +1.4 OK). fwd 는 두 줄이 정하므로 정렬 증거가 아님.

## 3. 절차 변경 — 방출
- **접지 인계 → 워밍업 완료 → 정책 안정 3~5 s 확인 → 방출은 한 번에**: 60 % 지지 근처까지 내린 뒤, 나머지를 **2~3 s 안에** 완전히 느슨하게 푼다. 천천히 계속 푸는 방식(0912)은 부분지지 구간(40~63 %)에 8~24 s 머물렀고 5회 전부 그 구간에서 넘어졌다.
- 앞·뒤 줄이 같이 풀리게(찰나의 차이는 무시해도 됨 — 승윤님 손 확인 0912).
- 방출 중 줄·윈치를 옆으로 옮기지 않는다.
- 롤이 5° 를 넘어 계속 커지면(콘솔 좌/우) 즉시 재인장 → 시도 무효 기록. 정책이 느린 기울기를 못 잡는 것은 확인된 사실이므로 기다리지 않는다.

# IMU 사전 기록 (1005) — 회복 cue·조기 복귀를 배포 가능 신호로 교체, 보류 seed 3·4

검토 13회차: 현재 후보(ce2)는 특권 신호를 쓴다. 참 몸통 속도(cue 방향·조기 복귀)와 접촉 힘 기반 하중 수용이다. 실물에는 선속도 센서가 없다.
또 여러 팔을 seed 1·2에서 골랐으므로 선택 편향이 있다.
- 팔(21793, 지연 4, **seed 3·4**, sf15 fs80 fi40 b18 nd):
  · k0 = 대조(C5만)
  · kp = 특권 신호 후보(ce2: cue_dir 0.0 + sw_early 0.25,6,0.2)
  · ki = 배포 가능 신호: cue 방향 = 켜짐 순간 IMU ω_y > 0, 조기 복귀 = 켜진 뒤 0.6 s·감지기 기울기 < 6°·|ω_xy| < 0.4·양발 접촉(0/1) 0.2 s
- 판정(사전): ki 가 kp 이득(대조 대비 전방 3조건 낙상 감소)의 ≥ 70 %를 유지하고 b18·nd 비퇴보 → 후보 유지(배포 계약 후보 = ki).
  < 70 % 이면 "회복 개선은 특권 신호 조건부"로 정정한다. kp 이득이 seed 3·4 에서 사라지면 선택 편향으로 정정한다.

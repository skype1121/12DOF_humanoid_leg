# 앞뒤 균형 복원항(pitch_comp) 실물 튜닝 카드 — 0923

## 왜 이걸 하나
0922 3회차 실물에서, 몸이 앞으로 15.3° 기우는 동안 정책의 발목 명령은 **평발 기하선(−1.00 °/°)을
그대로 따라갔다.** 그 선을 따라가면 발목은 몸이 도는 것을 전혀 막지 않는다. 기하 보정을 넘어선
복원 작용은 잔차 기울기 −0.021 °/°, 즉 0 이었다.

같은 정책이 시뮬에서는 +0.346(지연 6틱)~+0.643(지연 11틱)을 냈고, 같은 실물 시행에서도
**손이 받치는 동안에는 +0.39** 를 냈다. 모자란 것은 그 항 하나뿐이고 **파라미터도 하나(K)** 다.

정책을 다시 학습해서 이걸 만들려면 세대 하나가 든다. 명령 위에 더하는 것은 실물에서
이득 하나를 맞추는 일이다. 그래서 이 길을 먼저 간다.

## 무엇이 더해지나
매 틱, 정책 명령 뒤·블렌딩 앞에서:

    pitch  = atan2(g_x, −g_z)          (+ = 앞기울임, 시뮬·브리지 같은 정의)
    f     += (dt/τ)·(pitch − f)
    off    = clamp(K·f, ±limit),  틱당 |Δoff| ≤ slew
    왼 발목 += off,  오른 발목 −= off

부호 근거: 앞으로 기울 때 왼발목을 기하선보다 **더 +**, 오른발목을 **더 −** 로 쓰면 버틴다.
`tests/test_pitch_comp.py` 가 이 부호를 고정한다(8/8 통과). **부호가 반대면 낙상을 가속한다.**

## 켜기 (젯슨에서)
    python3 ~/humanoid_repo/jetson/scripts/set_pitch_comp.py --K 0.35 --guard-mode data
    # → 맵 사본 전부에 같은 값을 쓴다(한쪽만 고치면 다음 기동이 막힌다)
    # → 적용에는 **브리지 재기동** 필요 (맵은 기동 시 1회 읽는다)

기본값: K 0.35 · τ 0.06 s · limit ±8° · slew 1.0°/틱 · gate any · clamp ±25°
- τ 는 0.06 s 로 짧게 둔다. 이미 실측 320 ms 루프 지연이 있어서, 여기서 또 늦추면 복원이 늦는다.
- gate 는 `any`. 낙상 중 한 발이 떠도 복원항을 끊지 않는다.
- limit ±8° 는 발목 소프트 한계(왼 +39/오른 −39)에 여유를 남긴 값이다.

## guard_mode = data 가 바꾸는 것
승윤님 지시(0923): "발진 해도 상관없다. 가드 때문에 로봇이 먼저 꺼져서 데이터가 안 쌓인다."

| 가드 | safe(기본) | **data** |
|---|---|---|
| 발진 가드(피드백) | 정지 | **기록만** |
| 타깃 발진 가드 | 정지 | **기록만** |
| 리프트 가드(양발 무접촉) | 정지 | **기록만** |
| 과속 12 rad/s | 정지 | **정지(유지)** |
| 센서 스테일 | 정지 | **정지(유지)** |
| 중력 게이트(기동 시) | 거부 | **거부(유지)** |

과속은 발진이 아니라 기구 보호 한계라 남겼다. 기록만 하는 가드는 블랙박스에
`*_noted` 이벤트로 남는다(사유가 바뀌거나 1초마다).

**회수 절차는 아무것도 바뀌지 않았다**: 줄 인장 → 스택 종료 → release_all. 이 모드는
로봇이 안 멈추므로 줄과 손으로 회수를 책임지는 전제다.

## 시행 절차 (1회 = 약 3분)
1. 콘솔에서 평소대로 준비 → level 자세 → 정책 인계.
2. 넘어질 때까지 둔다. 손으로 잡지 않는다 — 잡으면 그 시행의 복원항 측정이 오염된다.
3. 넘어지면 평소 회수.
4. 내가 블랙박스를 읽고 다음 K 를 정한다.

## 판정 지표 (시행마다)
무보조는 지금까지 한 번도 성공한 적이 없다. 그래서 성공/실패가 아니라 **연속량**으로 본다.

| 지표 | 지금(0922 3회차) | 보고 싶은 것 |
|---|---|---|
| 인계 → 피치 10° 도달 시각 | 1.9 s | 길어지는가 |
| 잔차 기울기 dR/d(피치) | −0.021 | + 로 가는가 (목표 +0.35) |
| 발목 명령 최대 | 32.9° | 39° 소프트 한계를 넘지 않는가 |
| 발진 감지(`osc_guard_noted`) | — | 몇 초째, 몇 Hz 인가 |

**K 를 올려도 피치 10° 도달 시각이 안 늘면 이 가설은 틀린 것이다.** 두세 시행 안에 판가름난다.
그때는 되돌리고(`--off`) 다음 후보로 간다.

## 되돌리기
    python3 ~/humanoid_repo/jetson/scripts/set_pitch_comp.py --off --guard-mode safe
    # + 브리지 재기동

## 실험 W2gs (보행 challenger)
- Hypothesis: sb0 사건 보상(고정 착지 창 2–10 cm·놓친 스텝 −20)이 보폭을 묶는다. 클록 접촉 일정으로 바꾸면 걸음은 강제되고 보폭은 속도 추종을 따라 자유로워진다.
- Changed variable: 걷기 모드 sb0 사건·스윙 9항 → gait_schedule_walk(가중 2). 부모 W2q 25590, 500 반복.
- Expected signal: 스윙당 이동(vx/cadence)이 명령과 함께 증가.
- Success: 실제 vx 기울기(0.05→0.15) ≥ 0.3, 걷기 낙상 ≤ 8 %, 교대 ≥ 90 %.
- Kill: +300(25900)에서 낙상 > 15 % 또는 교대 < 80 % 또는 보행 소실(vx < 0.03).

## PR0 결과 — 자세 복귀는 주 병목 아님

- nd 의 '미복귀 100 %'는 지표 산물이다(외란 없으면 rest_t 미기록).
- 결정: 회복 병목은 A(짧은 첫 걸음)·지연. 다음 = A 원인 분해(평가 전용).

## 실험 A-DEC (평가 전용)
- Hypothesis: 짧은 첫 걸음은 시간 부족(지연 때문에 스윙이 짧다)이다.
- Changed variable: 지연 1 vs 4(KE, 관측 신호, seed 1·2, sf15 fs80 fi40).
- Signal: 낙상 env 의 td1_len·td1_t·여유 분포.
- 판정: 지연 4 에서 첫 걸음 길이가 줄고 착지가 늦으면 → 시간 부족(지렛대 = 실물 지연 단축·예측). 길이·시각이 같으면 → 정책 선택(지렛대 = 스텝 목표 cue·학습).

## 실험 WOM (보행 구조 challenger)
- Hypothesis: 고정 보폭은 sb0 계보의 보상 구조(사건·|vx| 게이트) 탓이다. OSS 형 전방향 보상 + 명령 노름 게이트면 보폭·속도·요가 명령을 따른다.
- Changed variable: 보상 세트 전체 교체(+명령 범위 vx −0.15~0.2·vy ±0.1·yaw ±0.5). 관측·DR·cadence 클록 불변. 1차 = W2q 25590 에서 500 반복(빠른 신호), 2차 = 처음부터(신호 있으면).
- Expected signal: vx 기울기 상승, 스윙당 이동 증가, vy·yaw 추종 출현.
- Success(+500): vx 기울기(0.05→0.15) ≥ 0.3, 걷기 낙상 ≤ 10 %, 교대 ≥ 85 %.
- Kill(+300): 걷기 낙상 > 20 % 또는 교대 < 70 % 또는 보행 소실.

## A-DEC 결과 — 'A = 시간 부족' 기각, 지연은 착지 뒤 안정화(폐루프)를 망친다
KE, seed 1·2, 지연 1 vs 4: sf15 14.2 vs 41 % (p 3e-15) · fs80 37.6 vs 66 % (p 9e-15) · fi40 15.1 vs 49 % (p 2e-16).
첫 걸음 길이(전체 중앙): sf15 11.6 vs 11.7 · fs80 20.0 vs 16.9 · fi40 25.2 vs 26.1 cm, 착지 시각 차 ≤ 0.1 s. 첫 착지 여유 sf15 −0.7 vs −3.1 · fi40 +5.3 vs +3.0 cm.
→ 걸음 기하·시각은 거의 같고 낙상만 2–3배 → 지연은 착지 뒤 안정화를 망친다(fi40 은 여유 양수에서도 3배).
- 기각: A 를 '시간 부족'으로 보는 가설.
- 회복 최대 지렛대 = **실효 지연**: 실물 단축(배포 체인)·3–5틱에 강한 안정화. 서브에이전트 3(sim2real/deploy)에게 지연 경로 분석을 맡긴다.
- 학습 쪽 후보(구조): 회복 정책을 지연 3–5 중심으로 **처음부터/다른 계보로** 학습(G25D 이어 학습 지연 DR 0–5 는 무효였다 — 이어 학습 틀의 한계 의심).

## 실험 WOMS (보행, 처음부터 학습)
- Hypothesis: 고정 gait 는 기존 계보 초기화에 갇힌 것이다. 처음부터 OSS 형 전방향 보상(WOM 설정)으로 학습하면 vx 비례·뒤·옆·제자리 교대 회전이 나온다.
- Changed variable: 초기화(무작위, resume 없음). 환경 = WOM(관측·DR·cadence 클록·배포 계약 불변).
- Signal: 전방향 평가(--cmd_set)에서 명령 방향으로 걸음·이동.
- Success(3000): vx 기울기 ≥ 0.4, 뒤·옆 명령 실제 속도 방향 일치(≥ 50 %), 제자리 회전 |ωz| ≥ 0.2 + 유효 cadence > 0.5 Hz, 걷기 낙상 ≤ 10 %.
- Kill: 1000 에서 걷기 소실(유효 cadence < 0.3 Hz) 또는 낙상 > 30 % 또는 명령 반응 전무.

## 실험 DROP (새 시작 경로 모사, 평가 전용)
- Hypothesis: 지그 해제 낙하(수 cm) → 홀드 착지 → ~1 s 뒤 정책 인계 경로에서 KE 는 정상 지면 출발과 같은 서기·회복 성능을 낸다.
- Changed variable: --spawn_dz 0 / 0.03 / 0.06 m, --precheck_s 1.2(인계까지 짧게, 실물 착지 0.4–1.4 s 뒤 시작 모사). KE, 지연 3, seed 1·2, nd sf15 b18.
- 지표: 사전 홀드 통과율(낙하 뒤 홀드로 서는가), nd 낙상·오탐, sf15·b18 낙상.
- 판정: dz 0.06 에서 홀드 통과율 ≥ 90 %·nd 낙상 ≤ 1 %·오탐 비증가 → 새 시작 경로 시뮬 확인. 미달이면 실물 절차에 '낮게 매달기(≤ 3 cm)' 조건을 넣는다.

## DROP 결과 — 사전 기준 미달: 1.2 s 시작은 이르고, 6 cm 낙하는 정착이 안 된다
(KE, 지연 3, seed 1·2, 정책 인계 = 스폰 1.2 s 뒤)

- 함의: 새 시작 게이트(양발 0.3 s + 낮은 ω 0.1 s 또는 최대 1 s)는 정착 전에 시작할 수 있다. 실물 절차에 '낮게 매달기(≤ 3 cm)'가 필요하다.

## DROP2·시작 게이트 — 정정(검토 16회차)
- DROP2 결정 규칙('통과 env 중 nd ≤ 1 %가 되는 최소 지연')은 잘못된 최적화였다. 시작을 늦추면 실패가 '홀드 중 낙상'으로 옮겨갈 뿐이다.
- 시작부터 끝까지 성공(nd, 256 env): 3 s 기준 84.8 % · 1.2 s 87.5 % · 3 cm 낙하 1.2/2.0/3.0 s 77.7/76.6/76.6 % → **이른 시작이 같거나 낫다.**
- 실물에서는 홀드 실패도 낙상이다 → 브리지 착지 게이트 변경(최소 2 s)을 **되돌렸다**(커밋 f00d3285). 원래 게이트(양발 0.3 s + 정착 0.1 s, 상한 1 s) 유지.
- 남는 사실: 3 cm 낙하는 0 cm 보다 시작부터 끝까지 성공이 약 7–10 %p 낮다(홀드 착지 정착 실패) → '낮게 매달기'는 여전히 권장.

## KAP — 정정

# WTOR 결과 (1005) — 무효: 설정이 물리에 반영되지 않음

r 0 / 0.008 / 0.015 m 세 조건의 모든 수치(낙상·추종·요 표류·착지·진동)가 소수점까지 동일했고, 기준선(`wenv_w2h24791_d3`)과도 같았다.
`[torsion]` 출력은 확인됐지만 결과가 비트 단위로 같다. 따라서 이 자산·GPU PhysX 경로에서 CollisionPropertiesCfg.torsional_patch_radius 는 효과가 없다(미적용 또는 미지원).
**결론 없음.** 요 표류의 접촉 모델 기여는 미판정이다. 참고로 이전 T4에서는 마찰 ×2.5가 표류를 −43 % 줄였다(접촉 민감성 간접 증거).
옵션 `--torsion_r` 은 남기되 '효과 없음 확인' 주석을 단다. 학습 DR 후보로 쓰지 않는다.

# 7차 실기 1차 시도 (2026-09-07 저녁) — 착지 중단, 하중 미완

세션: 젯슨 `~/logs/sessions/session_20260907_212628` (465s, 9197샘플, 20Hz).
젯슨 주소가 DHCP 로 **172.16.35.89** 로 바뀌었다(0906 까지 .64).

## 결론
정지·홀드 성능은 완벽했고, **막힌 것은 착지 기하와 좌우 하중 분배**다. 하중을 다 싣기 전에 중단하고 전원을 내렸다.
정책은 투입하지 않았다.

## 0단계 — 전부 통과 (단, 세 군데가 막혀 있었다)
| 게이트 | 결과 |
|---|---|
| 영점 boot_pose_check | 12/12 (재앵커 후) |
| IMU | 100Hz, 기울기 0.6~0.7°, 중력 (0.00,0.01,−1.00) |
| 압력→발력 | 10Hz 양쪽, calibrated |
| 브리지 selftest | ALL PASS |
| CAN | ERROR-ACTIVE, bus-off 0 |

막혀 있던 것 3건:
1. **CAN 어댑터** — PEAK PCAN-USB 수리 입고. 대체 candleLight(1d50:606f)는 젯슨 커널에 CONFIG_CAN_GS_USB·
   CONFIG_CAN_SLCAN 이 둘 다 not set 이라 인터페이스가 생기지 않는다(쓰려면 gs_usb 아웃오브트리 빌드).
   ⚠ "can1 안 붙고 can0 붙더라" 의 정체 = can0 는 젯슨 내장 mttcan 이라 어댑터 없이도 항상 UP. **모터 버스 증거 아님.**
   PCAN 복귀 후 can1 정상(fw v8.4.0).
2. **발압력 I2C 커넥터 이탈** — ADS1115 0x48/0x49 가 `/dev/i2c-7` 에서 **완전히 사라짐**(버스 전체 공백,
   `[Errno 121] Remote I/O error` 2초마다). 재체결로 복구. 콘솔 발력은 0N 과 무데이터를 `fresh.foot` 로만 구분한다.
3. **selftest 회귀(자작)** — 젯슨 구 자산 정리(d5b1dd9)로 walk 를 지웠는데 콘솔 버튼이 --checkpoint 를 안 넘겨
   기본값 walk 를 필수 로드 → FAIL. d6fe820 로 수정(콘솔이 드롭다운 값 전달, 브리지 기본값 STAND_DEFAULT).

## 영점 재앵커 (6fe19d3 상세)
- 왼 힙R·무릎이 정확히 +1창(36°) 시프트 → 배수 보정. 지그로 편 무릎이 33° 굽었다고 읽힌 것이 물증.
- 지그 자세에서 재캡처. **재현성 검증**: 오른다리를 접었다 지그 복귀 → 12/12, 잔차 8개 1° 이내·최대 3.02°.
- 8월 대비 발목 피치 왼 +10.49°·오른 +15.89° = **발목 모터 기구적 재장착**(승윤님 확인). 영점이 흡수하는 항목.

## 착지 실측 (실패한 축)
| 시각 | 전후 기울기 | 왼발 | 오른발 | 총합(체중 172.9N 대비) |
|---|---|---|---|---|
| 접지 직후 | **−2.6°** | 36N | 81N | 117N (68%) |
| 하중 증가 | −0.7° | 36N | 88N | 124N (72%, 최대) |
| 이후 | **+6 ~ +14.4°** | 4~15N | 45~88N | 49~100N |

1. **접지 직후 −2.6°** — 시뮬 명목 정착 피치 −1.9°, 0804 실측 −1.7° 과 같은 대역. 정착 피치 실측 항목은
   부분 획득(단, 윈치가 하중 28%+ 를 들고 있어 자유 정착이 아님 — 확정값 아님).
2. **하중이 실릴수록 앞으로 감** (−2.6° → +14.4°). 브리지 중력 게이트 한계(≈17°)에 근접.
3. **좌우 30:70 쏠림** — 좌우 기울기는 1~2° 뿐인데 하중은 오른발에 2배 이상. 골반은 수평인데 발만 쏠린다
   = 왼발 미접지 또는 발 위치 어긋남 의심. **다음 착지의 1순위 체크 항목.**
4. 총합이 체중의 72% 를 넘지 못함 — 윈치가 계속 3할 가까이 부담.

## 부수 실측
- **패드 압축 ≈1mm**(손가락, 계측 불가). 카드 기준 지면강성 1e4급 경계 → 시뮬 `--ground_k` 스윕에서
  k≤1e4 는 정책 전멸 조건. 0906 서보 강성 DR 발견과 같은 방향(**실물이 시뮬보다 무르다**). 다음 세대 학습 조건 후보.
- hang_stand 안전 이탈 검증: 전원 차단 시 "모터1 피드백 두절 → 소프트 램프다운 후 릴리즈"(rc=2) 정상 동작.

- Hypothesis: 실물 브리지의 감지기 입력은 정책 관측과 같은 신호(지연 0–3틱·잡음 ±0.05 자이로, 지연 중력, 실물 계약 패드 0/1)다. 참값 입력으로 얻은 kr 이득이 이 신호에서도 유지된다.
- Changed variable: --det_from_obs(감지기·상대 기울기·cue 방향 ω_y·조기 복귀·불응기 입력 = 관측 최신 프레임).
- 조건: 21793, **seed 3·4**(보류), 지연 3·4, sf15 fs80 fi40 b18 nd. 팔: k0(C5만) · kr(참값) · krobs(관측 신호).
- Success: krobs 가 kr 이득(대조 대비 전방 3조건 낙상 감소)의 ≥ 70 % 유지 + 재켜짐 ≤ 20 % + nd 오탐 비증가 → 시험 카드 유지.

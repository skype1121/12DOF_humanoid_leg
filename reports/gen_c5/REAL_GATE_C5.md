# C5 실물 진단 게이트 (사용자 1004 밤 합의 — 결과 보기 전 고정)
목적: 배포 승격이 아니라 **C5 구조 검증**(G21a → G24R → G21a 전환이 실물에서 매끄러운가).

## 시뮬 마지막 게이트
| # | 항목 | 기준 | 상태 |
|---|---|---|---|
| G1 | 상대 감지기 시뮬 | sf10/12/15·sb10·b18·nd·d3nd 에서 기존 C5(절대) 대비 퇴보 없음(짝 p ≥ 0.1 또는 개선), 오탐 < 2 %, 채터 0 | 평가 중(rel_c5b) |
| G2 | 감지기 실물 로그 재생 | 밀기 밖 회복 체류 0–5 %, 채터 없음 | **PASS**(1003 G21a 0.0 %) |
| G3 | 회복 체크포인트 확정 | restore_lr 대조군(cont-lr) 완료 → 21793·cont-lr·g-lr 중 하나, 마지막 4 체크포인트 일관성 | 학습 중 |

| G6 | 실물 힙 영점 재측정 | 시험 직전 현장 확인(승윤님) — 곡선상 위치 판단 | 현장 |

## 실물 진단 순서 (승인 뒤, 하네스 아래)
1. 하네스 무외란 서기(G21a 단독 기동 확인) → 2. 감지기 오탐 없음(서기 60 s 회복 모드 0) →
3. 아주 약한 앞 밀기: G21a 유지(전환 없음) 확인 → 4. 조금 더 센 밀기: G24R 전환 확인 → 5. 회복 뒤 G21a 복귀 확인. 여기까지.
**즉시 중단**: 전환 순간 액션 점프 과대, 3 Hz 재발, 회복 모드 고착(밀기 없이 > 5 s), 채터(1 s 안 켜짐/꺼짐 반복).
주 지표 = 낙상률이 아니라 전환의 매끄러움(블랙박스: 모드·전환 시각·두 정책 원시 출력·목표 점프).

## 승인 필요(자동 수행 안 함)
젯슨 파일 반영·배포, 실물 정책 실행, 모터 구동, 실물 밀기, 하드웨어맵/영점 변경.

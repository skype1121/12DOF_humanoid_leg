# +400 체크포인트(22200) 중간 평가 — C5 안, 같은 경로 짝
| | sf12 (seed 1–4) | sf15 (seed 1–2) |
|---|---|---|
| C5 기본 (G24R-a 21793) | 10.5 % | 31.4 % |
| **cont 22200 (변경 없음 이어 학습)** | 13.5 % (vs 기본 22/9, p 0.03) | 36.4 % (p 0.05) |
| G24R-e 22200 (feet_gap 회복 중 적용) | 16.2 % (vs cont 21/9, **p 0.04**) | 40.0 % (vs cont p 0.24) |
- 이어 학습만으로 C5 앞 회복이 나빠짐 → 21793 은 이 설정의 국소 최적점; **분기 효과는 cont 대비로만 판정**(검토 2회차 지적 실증).
- G24R-e 는 cont 보다도 나쁨 — feet_gap 가설과 dx2 순서 진단(좁은 간격 = 결과) 둘 다 반대 증거. 사전 fail-fast 판정은 +1000 에서(규칙 유지, 학습 계속).
- 원인 확정 축은 숨은 힙 영점 편향(DX3) — 다음 분기 설계는 DX5/DX5f(트림 유지/소멸) 결과 뒤.

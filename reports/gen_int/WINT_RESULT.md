# WINT 결과 (1005, 통합 1단계) — 걷기 중 밀기 → 회복 정책 전환: 이득 없음

지연 3, seed 1, 그룹 n 100. 걷기 구간 낙상 %(대조 = 같은 seed 걷기 단독 WPUSH).
| 밀기 | vx .05 통합/단독 | .10 | .15 |
|---|---|---|---|
| 없음 | 0 / 0 (오탐 2/100) | 0 / 0 (1) | 0 / 0 (0) |
| 앞 램프 8 N | 14 / 19 | 35 / 30 | 48 / 44 |
| 앞 램프 12 N | 74 / 71 | 84 / 86 | 92 / 91 |
| 앞 충격 40 N | 92 / 93 | 94 / 96 | 94 / 94 |
| 뒤 18 N | 23 / 33 | 21 / 24 | 14 / 20 |
- **저역 감지(τ 0.45 s, 4.5°)는 정상 보행 오탐 0–2/100으로 쓸 만하다.** 밀기 감지도 밀기 0.x s 뒤로 빠르다.
- 그러나 회복 정책(서기 출발로 학습)은 걷기 운동량 + 밀기를 구하지 못한다. 앞 밀기 낙상은 불변이고 뒤 밀기만 소폭 개선(vx 0.05: 33 → 23)이다. → 사전 기준 미충족, 전환 구조는 중단한다.
- 부수: 정지 뒤 서기 구간에서 RV4 가 93 % 켜진다(걷기 시작 때 잡은 기준 자세 사용) → 통합 시 정지 순간 기준 재설정이 필요하다(낙상 0이라 무해하지만 고칠 항목).
- 결론: **걷기 중 앞 밀기는 걷기 정책 자체가 보폭·속도를 바꿀 수 있어야 해결된다**(속도 추종 실패와 같은 병목). 걷기 트랙 최우선 = 보폭 조절 능력 구조.

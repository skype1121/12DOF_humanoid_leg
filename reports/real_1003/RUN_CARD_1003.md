# 1003 교대 진단 실행 카드 — G12/v2 ↔ G21a/native EMA (승격 아님)

결정(승윤님 1003, 배포 시 최종): **G12 = `stand_crouch_g12`(v2 그대로, 1002 와 같은 동작)**, G21a = `stand_crouch_g21a`(학습 관측 필터 계약 act β0.27·jvel β0.25).
`stand_crouch_g12_ema0`(학습 관측 계약) 은 선택지로만 남김. 주의: G12 v2 는 joint_vel_ema 가 학습 계약과 다르다(1001 알려진 불일치) — 비교는 '1002 실물 G12 ↔ G21a'.

## 0. 배포 (승인 뒤)
1. `bash deploy/deploy_g21a_1003.sh` (dry-run): 로컬 매니페스트 `deploy/g21a_1003.md5` 10/10, 로컬 selftest 3종, 젯슨 md5·프로세스, 젯슨 맵 읽어 오기.
2. 제어 프로세스 없음 확인 뒤 `--apply --restart-console`. 젯슨 selftest 의 '관측 필터 계약(1003)' PASS 확인.
3. 콘솔 드롭다운 = g12(v2, 기본) · g21a · g12_ema0 · g11a.

## 1. 순서 (승윤님 1003 합의 — G12 실물 로그는 이미 있음: 0929 서기, 1001 밀기 2.7 Hz 튐, 1002 밀기 3.2 Hz 튐)
콘솔은 시험마다 브리지를 새로 띄움 → 관측 이력·EMA·직전 액션 상태 초기화. 콘솔 시험 설정 = 접지 후 인계 · stand_crouch_g21a (1003 적용됨).
| # | 정책 | 내용 |
|---|---|---|
| 1 | g21a | 무외란 서기 → 약한 앞 밀기 |
| 2 | g21a | 같은 절차 |
| (조건부) | g12 (v2) | **G21a 가 안 튈 때만** 같은 날 1회 — '오늘 상태·밀기 차이' 배제용 대조. G21a 도 3 Hz 로 튀면 생략(정책 무관 서명 → 플랜트 쪽) |

밀기 세기는 기존 G12 로그와 '밀기 0.5s Δ피치°'로 맞춘다(1002 = 1.32°). 1001·1002 G12 블랙박스는 같은 분석기로 기준 행을 만든다.

각 시도: 착지·인계 → 정책 → **무외란 서기 먼저(≥20 s)** → 같은 사람·같은 위치·같은 세기 앞 밀기 1회, 손 닿는 순간 **'밀기 기록'** 버튼 → 회수.
같은 영상 위치(측면), 같은 로거(세션 기록은 첫 조작 전 시작).

## 2. 중단 규칙 (가드 완화 없음)
- 무외란 서기에서 3 Hz 진동이 **바로 커지면** 밀기 없이 즉시 회수(줄 인장 → 스택 종료 → release_all).
- 밀기 뒤 발산·낙하 위험 시 회수가 데이터보다 우선. 손 보조가 들어가면 그 시도는 '보조 개입'으로 기록.

## 3. 분석 (`reports/real_1003/ab_analyze.py`)
```
python3 reports/real_1003/ab_analyze.py <bb1.jsonl> <bb2.jsonl> [<bb3.jsonl>] \
  --label g21a_1 g21a_2 [g12_대조] --timeline ~/logs/sessions/session_*/timeline.jsonl --out reports/real_1003/ab
```
- t0(밀기 시작) 우선순위: 영상 손 접촉 시각(`--push 파일:초`) > 콘솔 '밀기 기록' > 자동(신뢰 낮음 — 1002 에서 오검출 확인).
- 비교만: ① 3 Hz(피치각속도 2–4.5 Hz) 포락 최대·성장률 λ·우세 주파수 ② 이륙 → 착지 → 하중 수용(접촉 비트 대리, 영상 확인)
  ③ 정착 시간(밀기 후·착지 후). 같은 밀기인지 = '밀기 0.5s Δ피치°' 열로 확인.
- 자체 점검(1002 G12 v2, t0 = 44.1 s): 3.17 Hz · 밀기 Δ피치 1.32° · λ 4.4/s · 1.46 s 에 |Δ피치| > 15° — REAL_1002 와 일치.
- 블랙박스에 `obs_filter`(act β, jvel β)·`jvel_ema_mode` 가 매 기록 남는다 — 표의 관측필터 열로 실제 계약 확인.

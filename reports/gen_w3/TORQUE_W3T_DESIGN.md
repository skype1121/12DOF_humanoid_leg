### 1.3 토크의 어느 부분이 정적 지지이고 어느 부분이 충격·추종인가 [측정]
| 관절 | RMS | 주기 프로파일 몫(그 RMS) | 위상 내 분산 몫(그 RMS) |
|---|---|---|---|
| 힙 외전 | 12.4 | **94.7 %** (12.0) | 5.3 % (2.9) |
| 무릎 | 14.1 | **96.5 %** (13.8) | 3.5 % (2.6) |
| 힙 회전 | 7.3 | 92.6 % (7.0) | 7.4 % (2.0) |
| 발목 앞뒤 | 3.9 | 37.0 % (2.4) | 63.0 % (3.1) |
| 발목 롤 | 5.0 | 76.0 % (4.4) | 24.0 % (2.5) |
- E[τ²] = (위상별 평균의 제곱) + (같은 위상 안의 분산). 충격·떨림·env 차이는 둘째 항에 들어간다. 힙 외전·무릎에서 둘째 항은 3–5 % 다 → **부하는 걸음 패턴 자체**이고 게인·명령 속도·충격의 몫은 작다.
- 주기 프로파일 안에서의 구분:
  - 무릎: 지지 평균 18.6 N·m 는 그 자세의 한발 지지 정적 하중(23.5)의 79 % — **자세(굽힘)로 줄일 수 있는 정적 지지**다.
  - 힙 외전: 보폭 평균 8.3 N·m 는 "정적 요구 22.9 × 한 다리의 한발 지지 시간 비율 0.35 = 7.9" 와 맞는다(한계 0.8 배 팔에서도 7.4 대 7.0) — 골반 롤의 각운동량 균형을 지지 힙 외전이 맡고 있다는 뜻이다.
    이 방식의 걸음에서는 **한발 지지 비율이 같으면 줄지 않는 몫**이다(양발 지지 때 좌우 다리 힘 차이로 롤 운동량을 대 주면 줄지만 그 몫은 무릎 토크로 옮겨 간다 — 그런 걸음의 대조는 없다).
    그 평균을 접지 시간 내내 고르게 내면 RMS 10.0·피크 12.4 인데 실제는 RMS 12.4·피크 25(포화)다.
    즉 힙 외전 평균제곱 154 중 100(65 %)은 이 걸음 시간표의 하한이고, 54(35 %)는 **몰아 주는 방식**의 몫이다(시간표를 안 바꿔도 줄일 수 있는 부분).

### 2.3 "토크를 줄이는 걸음"을 막는 것 — 정리
| 줄이는 길 | 막는 항 | 막지 않지만 유인도 없는 것 |

| 더 긴 양발 지지(짧은 한발 지지) | **`w3_height`(+1.40/s, 창 0.12–0.88)** · **`w3_periodic`(창 0.12–0.88)** — 단위시험 [E]: 기본 창에서 긴 스윙이 짧은 스윙보다 초당 +1.33 높다 | `w3_valid`·`w3_imit` 는 짧은 스윙을 허용(참조 자체가 35 % 스윙) |
| 더 편 지지 무릎 | 없음 | 걷는 동안 무릎·골반 높이·토크를 보는 항이 하나도 없다. 행동 0 = 기본자세(명령 무릎 38.5° + 처짐 편향 → 물리 55°)가 닻 |

- 부수 사실: **전진을 붙드는 보상이 학습 조건에서 죽어 있다**(학습 로그 걷기 초당 `w3_stride` +0.007·`w3_place` +0.015·`w3_track` −0.16; 살아 있는 것은 `w3_drift` −0.19/s).

### 4.2 T4 의 설계 근거
- 걷기 보상에 지지 무릎을 묶는 항이 없으므로(§2.3) 작은 가중도 자세를 옮길 수 있다. 값 [측정, 운동학 접지]: 문턱 45° 에서 평균 0.338 rad(명령별 0.313–0.360) → −1.0 = −0.34/s. 문턱 40° 0.425 · 50° 0.250.
- 선형(초과분 그대로)인 이유: 밴드형 `knee_stance_flexion` 은 밴드 밖 0.15 rad 에서 0 으로 포화해 현 64° 에서 기울기가 없다. 문턱 아래에는 끌림이 없어 무릎 잠금 유인도 없다(단위시험 [G]).
- 골반 높이 목표를 고르지 않은 이유: 골반 중심 높이는 몸통 롤(지지 힙 둘레 회전)만으로도 오른다 — 롤 11.8° 면 기하로 2.9 cm 이고 현 걸음의 높이 변동이 31 mm 다(그동안 지지 무릎은 오히려 62 → 69° 로 굽는다). 무릎을 안 펴고 채울 수 있는 대용 지표다.
- `w3_imit` 와의 관계: 모방은 예정 스윙 다리만, 위상 창 v 0.25–0.75 에서 채점한다. 현 걸음은 스윙발이 v 0.88 에 착지하므로 창 안에서 접지 다리 벌점과 겹치지 않는다.
  지지가 45° 로 높아지면 참조 각(무릎 55–57°)의 스윙 다리는 바닥에서 약 2 cm 뜬다(같은 방향). 스윙발이 창 안에서 착지하는 걸음(T3 와 결합)에서는 착지 다리의 참조 55–57° 와 12° 어긋난다.
- 시뮬의 무릎 처짐 모형 주의: 물리 무릎각 = 명령 + 상수 편향(−10.5…−13.5°, `mdp_hang.py:1106–1114`) + PD 처짐. 편향은 양발 서기 하중으로 식별한 값이고 **하중에 비례하지 않는다.**
  실물 무릎 처짐이 하중 비례(탄성)라면 한발 지지(하중 약 2.5 배)에서 실물은 시뮬보다 더 굽는다 → 실물 무릎 토크 요구는 시뮬보다 클 수 있다 [가설 — 현장 확인 필요].

## 7. 확신 없는 부분
- **정역학 모델은 가속을 뺀 값이다.** 현 걸음은 탄도형이라 "정적 요구"는 그 순간의 실제 토크가 아니다(지지 힙 외전 22.9 대 실제 평균 14.1). 하한 표 (C) 의 "고르게"는 이상적 하한이고 실제로 그렇게 걸을 수 있다는 뜻이 아니다.
  관성 I = 1.15 kg·m² 는 스윙 다리를 강체로 붙인 모델값이고 자료의 롤 각가속에서 거꾸로 보면 0.8–1.9 로 흩어진다 — 롤 흔들림 열은 자릿수만 믿는다.
- **힙 외전 하한(M·d)은 "롤 균형을 지지 힙 외전이 맡는다"는 가정 위의 값이다.** 현 걸음에서는 맞지만(8.3 대 7.9, 7.4 대 7.0), 양발 지지 때 좌우 다리 힘 차이로 롤 운동량을 대는 걸음이면
  힙 외전 몫이 무릎으로 옮겨 갈 수 있다 — 하한은 같은 방식의 걸음 안에서만 하한이다. 무릎 하한도 CoM 앞뒤 위치·발목 토크 분담에 따라 약 ±7 % 움직인다.
- **한발 지지 비율**은 판정 방법에 따라 69–83 % 다(추적에 발 힘이 없다). 표 (C) 는 세 값을 모두 적었다.
- **가중 −40·−1.0 은 "기존 걷기 벌점과 같은 급"이라는 판단**이지 실험으로 정한 값이 아니다. PPO 가 무릎을 펴는 대신 스윙·전진을 깎는 쪽으로 갈 수 있다(§2.3 전진 유인 약함, W3S3f 사례).
- **T2 의 힙 외전 쪽 효과는 약할 수 있다**: 이륙 구간에서 정책의 PD 요구(33–37 N·m)가 한계를 넘어 있어, 요구를 3분의 1 넘게 줄이기 전에는 적용 토크(=벌점)가 변하지 않는다(탐색 잡음 표준편차 ≈ 8° 가 그 틈 4.6° 보다 커서 신호가 0 은 아니다).

  정책 관측에 몸통 선속도가 없어 env 마다 다른 속도 치우침(지연 1–5 틱·LPF·DR 에 따라 달라지는 응답 직선의 평행 이동 — 1005 기록 "영점은 배포 조건 의존 오프셋")을 고칠 수 없다.
  `w3_track` 은 오차가 명령보다 크면 음수다(e > |c|): 뒤 0.03–0.06·옆 0.03–0.04 전부와 앞 명령의 46 % 가 0.062 아래다. `w3_stride` 는 보폭 오차 0.056 m ≈ 1.9 σ 에서 exp(−3.5) ≈ 기준값 → 0.
- 민감도(`fwd_incentive.py` 2 절, env 별 보폭 오프셋 표준편차 0.056 m 를 넣은 기대값): 전진을 절반으로 줄일 때 잃는 보상(그 명령 동안, 초당)

### 8.3 `W3S3tF` — 단일 변경
- `w3_stride_lin`(새 함수, `rl_walking/w3.py` 끝): 병진 명령(|vx| 또는 |vy| ≥ 0.02)·걷기에서 유효 착지 사건마다 clip(Δp·ΔP*/‖ΔP*‖², −1, 1), Δp = 스윙발 이륙→착지 월드 변위(`w3_lat_tracker` 의 `td_dx`·`td_dy`), ΔP* = (vx/f, vy/f).
  제자리 디딤 0 · 목표 보폭 이상 1(더 가도 안 늘어남) · 반대 방향 음수 · 명령 0·제자리 회전·서기에서는 정확히 0. `w3_stride2` 의 반대 방향 벌점 항을 양수 쪽까지 편 식이다.
- 스윙발 자체의 변위를 쓰므로 몸 기울임·지지발 미끄럼으로는 못 받는다(1006 `w3_stride` 도입 때의 해킹 차단을 그대로 물려받음). 유효 스윙(공중 ≥ 0.12 s·정점 ≥ 3 cm)의 착지에만 준다(단위시험 [H]: 0.08 s 스윙은 0).
- 가중 +10(사건당, `w3_stride`·`w3_place` 와 같은 단위): 온전한 보폭이면 병진 명령 동안 +0.44/s. 명목 궤적에서의 현재 값: 앞 +0.38–0.41 · 뒤 +0.26–0.30 · 옆 +0.09/s.
- 쓰임: (a) 묶음에서 전진이 무너질 때 얹는 항 — `_w3t_progress(cfg)` 한 줄(예: W3S3f 위). (b) 단독 팔 `Biped12-HangStand-W3S3tF-v0`.
- 하지 않는 것: 명령 0 의 영점 표류(방향이 없어 0) — 1005 결론("영점 직접 대책은 학습 루프 밖: 명령 0 = STAND, 저속은 외부 속도 루프")을 그대로 둔다.
- 알려진 위험: 목표 보폭까지는 더 가면 더 받는 항이라 저속 명령에서 과속 쪽 치우침이 생길 수 있다(상한 1 과 `w3_drift` −3 이 막는다; W3S1e 의 과속 부작용과 같은 방향이므로 판정에 과속 상한을 둔다).
  옆걸음은 지금 스윙발 옆 변위가 목표의 23 % 뿐이라(나머지는 낮게 끌거나 미끄러지는 몫으로 읽힌다 — 운동학 판정이라 가설) 옆 명령의 걸음 모양이 바뀔 수 있다.

### 9.3 판단
- **(i) 자세로는 2 배가 안 나온다.** 물리 무릎각을 엔코더 값(처짐 0)부터 불일치 전부를 무릎에 준 값까지, 압력 중심을 ±2.3 cm 훑어도 모델은 5.3–9.1 N·m 이고 tau_est 3.91 은 그 0.43–0.73 배다.
  시뮬 서기 모델값 8.6 과의 차 4.7 N·m 가운데 자세가 설명할 수 있는 몫은, 처짐이 0919 실측(+10–12.5°)대로면 0.5–0.9 N·m(11–18 %), 처짐이 0 이라고 쳐도 2.2 N·m(47 %)까지다.
- **(iii) 질량이 아니다.** 모델 17.635 kg·저울 17.62 kg. 질량만으로 맞추려면 8.0 kg 이어야 한다.
- **(ii) 남는 것은 토크 추정 쪽이다** — tau_est 는 모델의 약 절반(처짐 10–12.5° 가정에서 0.49–0.51 배). 이 기록만으로는 "추정 눈금(전류 → 토크 상수)"과 "기어 마찰이 정지 하중 일부를 받침"을 가르지 못한다.
  단서(판정 아님): ① 힙 앞뒤도 tau_est +0.77 대 모델 +1.40 으로 0.55 배 — 무릎과 비슷한 비율(값이 작아 마찰·잡음과 같은 크기). ② 양발 접촉에서 무릎이 펴는 중·굽는 중의 |tau_est| 가 다르다(오른 6.29 대 3.21, 왼 3.33 대 2.27 → 반차 1.5·0.5 N·m = 마찰의 흔적)
  그러나 방향 평균(4.75·2.80)도 모델의 절반 근처다 — 마찰만이 원인이면 방향 평균이 실제 하중에 가까워야 한다(이 표본은 회복 동작 중이라 하중이 일정하지 않다). 두 단서 모두 눈금 쪽을 가리키지만 확정하지 않는다.
- 뜻: tau_est 가 실제의 절반으로 읽히는 것이라면 실물 구리손·전원 부하는 tau_est 로 셈한 값의 4 배다(`reports/real_1007/README.md` 보강 2 의 정정과 같은 방향). 시뮬 토크 예산(§1)을 실물에 옮길 때 "실물은 절반만 쓴다"고 읽으면 안 된다.

### 9.4 가르는 데 필요한 현장 측정(승인 사항)
- 하중이 걸린 채 무릎을 천천히 굽혔다 펴는 왕복(양발 서기에서 ±5°·2°/s 같은 느린 움직임)에서 같은 각의 tau_est 를 방향별로 본다: 차이 = 2 × 기어 마찰, 평균 ≈ 실제 하중 × 추정 눈금.
  평균이 모델값(약 7–8 N·m)에 오면 눈금은 맞고 서기의 3.9 는 마찰이 받친 것, 평균도 절반이면 눈금 쪽이다.
- 눈금 자체: 다리를 띄운 채 정강이를 수평 가까이 들고 알려진 추를 달아 tau_est 변화가 m·g·L 인지 본다.
- 물리 무릎각: 서기에서 넓적다리–정강이 각을 재면 §9.2 의 어느 행인지 정해진다. 같은 방법으로 한발 지지(보조 줄 상태)에서의 무릎 각을 재면 §4.2 의 처짐 가설(하중 비례)도 갈린다.

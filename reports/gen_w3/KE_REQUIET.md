# KE 감지기 "회복 모드 갇힘" 결함과 해소 후보(requiet) — 근거·확증 배터리 사전 등록 (2026-10-07, claude2)

> 상태: **후보 제안 전 단계**. 시뮬 탐색(X4·X5·X2f·X6)은 끝났고, 이 문서는 KE 단독 확증 배터리를 실행 전에 등록한다. 배포 코드에는 기본 꺼짐 옵션으로만 들어 있다.
> 젯슨 배포·실물 적용·승격은 사용자 결정. 시뮬 수치는 실물 확률이 아니다.

## 1. 결함(시뮬 측정)
- KE 감지기는 회복 모드 중 기준 자세를 갱신하지 않고, 평온 꺼짐은 "기준 대비 기울기 < 1.5°"를 요구한다. 밀린 뒤 서는 자세가 기준과 1.5° 넘게 달라지고 활성화가 가벼워 조기 복귀 자격(최대 편차 5° 또는 |ω| 1.0)이 없으면,
  로봇이 조용히 서 있어도 회복 모드가 끝나지 않는다.
- 크기: 깨끗한 KE 서기에 12 N 밀기 하나 → 7 s 뒤에도 회복 모드인 env 10.5 %(뒤)·15.2 %(앞). 그 상태에서 앞 램프가 오면 낙상 52–67 %(같은 env 의 대조 24–33 %). `TRANSITION_W3KE.md` §5.6f.
- 합성 구조에서는 기능 고장이 된다: 회복 모드 중에는 걷기 켜기가 거부되므로, 배포 코드 폐루프(X6)에서 외란 없이 갇힌 env(4/316)는 걷기를 시작하지 못하거나 1–2 s 늦었다. §5.10b·§5.10c.
- 실물: KE 키의 실물 기록이 없어 유무를 판단할 수 없다. "모드 중 기준 미갱신"과 "1.5° 조건이 꺼짐을 0.4–1 s 늦춤"은 1004 C5 기록에서 확인(§5.13).

## 2. 후보 규칙
회복 모드 중 **조용한 서기**(감지 |ω_xy| < 0.3 rad/s ∧ 접촉 조건)가 **2.0 s** 이어지면 기준 자세를 현재 자세로 다시 잡고 모드를 끈다. 다른 규칙은 그대로.
- 값의 출처: 2.0 s = 평온 유지 1.0 s 의 2 배, 0.3 = 현행 꺼짐 문턱. 결과를 보기 전에 정했고 바꾸지 않는다.
- 접촉 조건: 탐색(X5·X6b)은 **양발**. 확증 후보는 **감지기의 끄기 접촉 조건을 따름**(KE = 한 발 이상) — 실물에서 한쪽 패드가 0 을 낸 사례(1004 시험 4, 양발 조건 때문에 19 s 체류)에서 양발 요구는 발동하지 않기 때문이다.
  패드가 정상인 시뮬에서는 두 조건이 거의 같을 것으로 예상하며, 이 배터리가 그것도 확인한다(패드 고장 조건 포함).
- 구현: 시뮬 `eval_transition_dev.py --sw_requiet 2.0,0.3,off` / 배포 `c5_switch.SwitchDetector(requiet=(2.0, 0.3, "off"))`(기본 None = 종전 비트 동일, selftest 로 고정).

## 4. 확증 배터리 — 사전 등록 (1007 19:50, 실행 전)
- 하네스: 사본 평가기 KE 단독(`--dir ke2w3 --ke_mode none`: 처음부터 끝까지 KE, 걷기 없음), 지면 평가 태스크(느린 롤 토크 램프 DR 켬 — 기존 KE 평가와 같은 조건), 128 env, 추적 포함.
- 팔: **KE**(현행) / **KEq**(`--sw_requiet 2.0,0.3,off`). 보조 팔(imuH 와의 결합, 정보용): **KEH**(`--sw_early_imu 0.6,6,0.4,0.7`) / **KEHq**.
- seed: 21·22·23(이 저장소의 어떤 실행에도 쓰지 않은 값). 지연 2 는 3 seed, 지연 3 은 seed 21·22.
- 조건(시각은 인계 기준):
  | 이름 | 내용 | 지연 |
  |---|---|---|
  | nd60 | 무외란 60 s | 2·3 |
  | b18 / fi40 / sf15 | 4 s 에 뒤 18 N 0.3 s / 앞 40 N 0.2 s / 앞 램프 15 N | 2 (sf15 는 3 도) |
  | bb / fb | 4 s 에 뒤(앞) 12 N 0.3 s → 12 s 에 앞 램프 15 N | 2 (bb 는 3 도) |
  | padL | 왼발 접촉 비트 3 s 부터 0 고정 + bb 와 같은 외란 | 2 |
  보조 팔은 nd60·bb·fb(지연 2)만.
- 판정 기준(KEq 대 KE, 같은 seed·env 짝. 전부 충족해야 채택 제안):
  - **K1 이득**: bb + fb 의 둘째 외란 뒤 낙상이 3 %p 이상 줄고 짝 p < 0.05(개체 단위로 접은 검정도 함께 보고).
  - **K2 갇힘**: 둘째 외란 직전 회복 모드 env 가 bb·fb 각각 ≤ 2 %.
  - **K3 단일 외란 비열등**: b18·fi40·sf15 각각 낙상 +3 %p 이하, 세 조건을 합친 짝 검정에서 KEq 쪽 악화가 유의(p < 0.05)하지 않음.
  - **K4 무외란 60 s**: 낙상 KE + 1 env 이하 · 회복 켜짐 횟수(env·분당) +20 % 이하 · 회복 모드 시간 비율이 늘지 않음.
  - **K5 패드 고장**: padL 에서 둘째 외란 직전 회복 모드 env ≤ 5 % · 둘째 외란 뒤 낙상 KE + 3 %p 이하.
  - **K6 지연 3**: sf15 +3 %p 이하 · bb 갇힘 ≤ 2 % · nd60 낙상 +1 env 이하.
  - **K7 돌려주는 자세**: 재기준 발동 시점의 '묵은 기준 대비 기울기'가 6° 를 넘는 발동 ≤ 5 % · 발동 뒤 2 s 안 낙상 ≤ 발동 수의 2 %(발동 기록 `rqlog_*.json`).
- 보조(판정 아님): KEH 대 KEHq 의 같은 지표 — imuH 를 승격할 경우 두 변경을 함께 쓸 때의 근거.
- 하나라도 실패하면 기록하고 값 조정을 반복하지 않는다. 통과해도 실물 기록에서 서명을 확인하기 전까지는 "후보"다.
- **해석 고정 주석(1007 21:32 — seed 21·지연 2 의 중간값을 본 뒤에 적었다. 기준 값·문턱은 바꾸지 않고 읽는 법만 명시한다. 독립 검토가 대안 해석과의 차이를 계산함)**:
  - K1·K5 "둘째 외란 뒤 낙상": 분모 = 사전검사 통과 ∧ 두 팔 모두 12 s 직전 생존, 분자 = 12 s 이후 실행 끝까지의 낙상(`x4_summ.py` 선례와 같음). 분모를 통과 전체로 바꿔도 seed 21 에서 결과 같음.
  - K2·K5·K6 "직전 회복 모드": 그 팔에서 12 s 직전 틱에 살아 있는 통과 env 중 회복 모드인 비율.
  - K3 "낙상": 인계 뒤 전체 낙상, 분모 = 통과 전체. 검정은 정확 이항 양측 p < 0.05 이면서 후보만 > 기준만 일 때 실패.
  - K4: 낙상은 seed 합. 켜짐 횟수 = 회복 모드 상승 에지 / 생존 env·분, 시간 비율 = 회복 모드 틱 / 생존 틱. 기준선 켜짐이 seed 당 3 회 안팎이라 "+20 %"는 1 회 차이에도 갈린다 — 그대로 적용하고 그 사실을 보고한다.
  - **K7: 배터리의 모든 조건·지연·seed 의 발동을 합쳐서 본다**("발동 수의 2 %"라는 문장 그대로). 조건별 표를 함께 낸다 — seed 21 에서 합산은 충족(6° 초과 1 / 218, 2 s 안 낙상 3 / 218), 조건별로는 sf15 가 발동 5 건 중 6° 초과 1·낙상 2 다.
    이 해석 선택은 결과를 본 뒤의 것이므로, 판정 보고에서 K7 은 "합산 충족 / 조건별 표 병기"로 적고 sf15 의 낙상 2 건이 기준 팔에서도 같은 env·같은 시각에 일어났는지를 함께 적는다.

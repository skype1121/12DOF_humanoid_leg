## 1. 0912 와 달라지는 근거 (MEASURED / 계산)
0. **(0913 06시 정정, 가장 중요) 왼발 접촉 비트는 세션 내내 가짜였다.** 고착 패드 L[2]가 공중에서도 587 카운트(임계 200 초과)를 내 왼발 비트가 항상 1 이었고, T5 는 왼발의 살아있는 패드 3채널이 처음부터 끝까지 0 이었다. 즉 정책은 왼발이 떠 있어도 '양발 접촉' 으로 알았고, 오른쪽으로 느리게 구를 때 왼발 이탈에 반응하지 못했다(접촉 상실 직전엔 오른발 앞바깥 패드 하나만 남음). 왼쪽으로 굴렀다면 정상 패드가 0 을 내 정책이 반응했을 것 → 5회 모두 오른쪽인 이유의 유력 후보. **L[2] 제외(`left_pad_bias`)와 죽은 채널 진단은 이 기전을 직접 제거한다** — 이번 시험의 1순위 변경.
1. **가드는 원인이 아니었다.** 5회 모두 가드 정지 0건(T1 리프트 가드 제외). 정책은 넘어지는 동안에도 살아 있었다. 가드는 바꾸지 않는다.
2. **정책은 느린 기울기(≤1 °/s·≤5°)에 반응하지 않았다**(롤 관절 목표 변화 ≤1.1°, 이득 0.11~0.13 °/°). 시뮬 v5 는 줄이 걸린 동안 접촉 천장 근처(홀드 14.6~15 보다 0.4~0.7 Nm 아래, 스텝 폭주)까지 버티지만, 줄이 없어진 뒤 상수 롤 모멘트 6 Nm 에는 31~55 % 만 생존(정적 토크 유지 능력 약함).
3. **부분지지에서 버틸 수 있는 외란 모멘트는 발 하중에 비례한다**(시뮬 홀드 천장 14.6~15 Nm @50 % 지지 = 접촉 한계). 지지가 남아 있는 시간이 길수록 작은 모멘트에도 넘어진다.
4. 구맵 영점 오차(힙 요 −7.5/−6.3° 등)는 제거됐다(재캡처). IMU 는 수평에서 lat +1.3° 를 낸다(장착 편향).

## 2.5 롤 보정기(roll_comp) — 켜려면 (기본 OFF, 승인 항목)
정책 밖 외부 루프: 정책에 주는 투영중력의 롤을 1차 저역(τ)으로 걸러 K 배를 양 발목롤 목표에 더한다(±한계, 슬루 0.25°/틱, 게이트 = 정책 구동 AND 접촉 비트 AND 접지 확인, 디바운스 0.2 s, 게이트 꺼지면 같은 τ 로 0 감쇠). 시뮬(v5, S8ac4 env): 줄 없이 6 Nm 31→98 %, 회귀 항목 ±2 pp 안, 9 Nm·15 Nm 램프·kp×0.4 는 물리 한계라 무이득. **확정값(시뮬, 로컬 맵에 enabled:false 로 기입됨): K 1.0 · τ 1.0 s · 한계 3° · ankle_r · sign +1 · lr [1,1] · gate any · 디바운스 0.2 s · 슬루 0.25°/틱 · 롤 클램프 15°.** 트레이드오프: 발 폭 한계(≈7 Nm) 밖 모멘트에선 스텝을 줄여 −14 pp(9 Nm 램프) → 첫 시도는 OFF 기준선, 같은 조건 ON 비교(A/B).
1. 젯슨 맵 **두 사본 모두**에 `imu_mount_bias_deg` 가 들어 있는지(브리지 selftest `[FrameMap] IMU 장착 편향 보정` 줄). 없으면 편향 1.3° 가 그대로 K·1.3° 의 상수 오프셋이 된다 → 켜지 않는다.
2. **방향 확인(승인·모터 토크 필요)**: 로봇을 매단 채(발 공중) stage8 홀드 상태에서 양 발목롤에 관절 프레임 +2°(모터 프레임 왼 −2°/오른 +2°)를 주면 **두 발바닥이 대칭으로 안쪽(사타구니 쪽 가장자리 아래)** 으로 굴러야 한다. 두 발이 같은 쪽으로 기울면 부호 규약이 틀린 것 → 켜지 않는다.
3. 맵 키 `roll_comp` 의 `enabled` 를 true 로(두 사본 동일, 다른 값 금지 — 서명 검사에 걸림) → 브리지 재기동 → selftest `roll_comp 활성` 줄·콘솔 상태줄 `보정기 ON` 확인.
4. 착지 뒤 콘솔의 보정기 오프셋이 ±한계 안에서 천천히(0.25°/틱 이하) 움직이고, 방출 중 롤이 커질 때 오프셋 부호가 롤 반대(오른쪽 기울면 음수)인지 본다. 이상하면 즉시 재인장·정책 정지(가드 불변).
5. 판정·중단 기준은 §3·§4 그대로. 블랙박스에 `roll_comp_deg`·`targets_deg_joint_pre_rc` 가 남으므로 시험 후 `analyze_correction_chain.py` 가 정책 출력과 보정기를 분리해 준다.

## 2.6 공중 응답 테스트 (다음 시험 첫 순서, 낙상 위험 없음)
0913 실물 5회에서 정책 입력(중력·자이로·관절각)은 시뮬과 정합했으나 롤에 대한 정책 응답이 시뮬의 1/3~1/5 였다. 정책이 실물에서 실제로 얼마나 보정하는지를 **매달린 채** 잰다.
1. air 모드로 정책 시작(발 공중, 워밍업 뒤). 2. 손으로 몸통을 천천히(약 1 °/s) 오른쪽으로 5° 굴렸다가 되돌리고, 왼쪽도 같이 — 2~3회. 3. 기록 종료 뒤 `python3 jetson/scripts/analyze_roll_response.py <rl_bridge_*.jsonl>` 로 발목/힙 목표 이득(°/°)·지연을 뽑아 시뮬 기준값(`promotion_criteria_v7.md` 공중 응답 표)과 비교. **공중 기준값(sig4, 매달림 + 롤 램프 3 Nm)**: 모든 정책이 롤 1~2° 에 힙 3~5°·발목 0.2~5° 의 목표 변화를 지연 ≤0.15 s 로 낸다(표의 플래토 Δ). 실물에서 손으로 5° 굴렸을 때 힙 목표가 수 도 단위로 즉시 움직이는지가 판정 기준이다(부분지지 램프 값 −0.4~−0.5 °/° 는 접지 상태 기준이라 여기엔 쓰지 않음).
4. 실물이 시뮬의 절반 이하이면 정책 이식 자체(관측 스케일·필터·지연)를 먼저 의심하고, 비슷하면 착지 기하를 잰다. 측정 순서(전부 무동력·낙상 위험 없음): ① **두 발 저울**로 좌우 하중 차 → 좌우 CoM 편심(편심 ≈ 발 간격 × 하중 차 비율 / 2; 시뮬은 연성 kp ×0.5 에서 편심 2 cm 부터 23 % 낙상, 3 cm 81 %, 4 cm 100 % — `promotion_criteria_v7.md` 재현 경계 표) ② 후크 연직선 vs 골반 중심(후크 오프셋 단독은 시뮬 ±8 cm 까지 낙상 0 이라 후순위) ③ 홀드로 세운 뒤 왼발 뒤꿈치 종이 테스트(왼발 뒤 채널 0 의 원인) ④ 매달림 자세에서 콘솔 lat 이 +1.2 ±0.5 인지.
5. 시뮬 재현(kp ×0.5 + 편심)은 **왼발 이탈 → 오른쪽 롤** 순서는 실물과 같지만 기전이 다르다(시뮬은 자이로 ~28 °/s 진동·관절 7~17° 스윙·정책 목표 15~36° 요동의 동적 낙상, 실물은 1~4 °/s 준정적·관절 ≤1.4°·정책 출력 ≤3.6°). 따라서 편심 측정값이 2 cm 미만이어도 실물 기전이 배제되는 것은 아니다 — 측정은 '무엇이 아닌가' 를 좁히는 용도.

## 3. 절차 변경 — 방출
- **접지 인계 → 워밍업 완료 → 정책 안정 3~5 s 확인 → 방출은 한 번에**: 양발 접촉 표시 뒤 정책이 3~5 s 안정된 것을 보고(콘솔에는 지지비 표시가 없고 패드 % 는 미보정이라 '60 %' 는 잴 수 없다 — 줄이 아직 하중을 나눠 갖는 상태에서), 나머지를 **3~5 s 안에** 완전히 느슨하게 푼다. 천천히 계속 푸는 방식(0912)은 부분지지 구간(40~63 %)에 8~24 s 머물렀고 5회 전부 그 구간에서 넘어졌다. 근거는 물리 논리(중립 구간 체류 최소화)이지 시뮬 성공률이 아니다 — 시뮬은 느린 방출도 97~99 %(v5)로 벌하지 않는다(`analysis §4.11`). v6 를 쓰면 2 s 급 방출은 −8 pp 라 5 s 안팎이 무난.
- 앞·뒤 줄이 같이 풀리게(찰나의 차이는 무시해도 됨 — 승윤님 손 확인 0912).
- 방출 중 줄·윈치를 옆으로 옮기지 않는다.
- **(0913 저녁, 승윤님 결정) 공중 시작(air) 모드의 재착지 허용**: 접지 확정 뒤 양발이 1 s 넘게 떨어지면 종전엔 동결이었으나, 이제 공중 허용 상태(새 120 s 창)로 되돌아간다(최대 5회, 브리지 HangGuard). 줄 느슨·자립 판정(FREE_STAND) 뒤의 재들림과 접지 인계(ground) 모드는 종전대로 동결. 착지 후 발력이 한쪽에 몰렸으면 다시 들어 후크를 옮기고 재착지해도 된다.
- 방출 중 중단 기준은 0911 카드 그대로 **좌우 기울기 3° 초과 증가**(또는 |fwd|>12°, 한 발이 눈에 띄게 뜸, 가드 정지) → 즉시 재인장 → 시도 무효 기록(0913 초안의 '5°' 표기는 근거 없는 완화라 철회). 정책이 느린 기울기를 못 잡는 것은 확인된 사실이므로 기다리지 않는다.

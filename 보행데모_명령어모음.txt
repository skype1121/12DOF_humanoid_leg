■ 7. 문제 해결 체크리스트
───────────────────────────────────────────────────────────────────
1) walk_demo/UI가 "접속 실패"
   → 아이작심 + MCP 확장이 떠있는지 확인 (0번 명령어)
2) UI 상태가 "― 미연결 ―" 고정
   → pkill -f "scripts/walk_ui"  후  python3 scripts/walk_ui.py
3) 로봇이 넘어져서 이상함
   → UI [♻ 리셋]  (또는 아이작심에서 Stop▶Play)
4) 클로드가 아이작심을 못 볼 때
   → 클로드 터미널 세션 재시작 (MCP 도구는 세션 시작 시 로드됨)

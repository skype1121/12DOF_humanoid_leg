# Codex 메타 검토 (읽기 전용) — 밤샘 시뮬 학습이 실물 문제를 고칠 수 있나

맥락(파일): `reports/real_0910_A1/plan_next_test.md`(§1 원인·§6 Codex 반박·§7 패드), `reports/v6_design/v6_design_v1.md`, `reports/real_0910_A1/README.md`.
확정 사실:
- 실물 3회 실패는 **하중 이전 중**(발력 62→10%) 로프가 당겨 몸이 p1축 대칭 회전. 정적 저지지 자립에 도달하기 전에 실패.
- sim 대조군: 홀드 0/256(정적 불안정=능동균형 필수), v5 CoM sweep −0.04→−0.10 = 91.8→43.4%.
- 실물 CoM 은 0908 기준 발목축 뒤 ≥26mm(−0.026). 발 지지면 −64~+84mm(Codex 실측). 즉 실물 CoM 은 지지면 안(마진 작음)이고, v5 는 com_fix −0.03~−0.05 에서 80~92%.
- sim 지지 모델(`mdp_hang._apply`)은 수직 상수힘 r(t)·mg 선형 감소 + 진자 복원 + 레벨링 토크. **길이 제약 케이블(당김이 자세와 결합)이 없다.**

핵심 질문(반박·정량):
1. 실물 실패 병목이 "전이 중 로프 동역학"(sim 부재)이라면, sim CoM sweep 을 목표로 v6 를 반복 학습하는 것은 **프록시 최적화**로 헛수고 아닌가? v5 가 이미 실물 CoM(−0.03~−0.05)에서 80~92% 인 점을 감안하면, 남은 실물 실패는 학습이 아니라 절차(빠른 슬랙)·기구(후크 정렬)·계측으로 풀어야 하는 것 아닌가?
2. 그럼에도 밤샘 학습이 값어치 있으려면 어떤 sim 변경이 실물 병목을 담아야 하나? (케이블 길이 스케줄 모델 없이, 기존 힘 모델에서 근사 가능한 최소 변경은?)
3. v6c2(앞기울임 허용+CoM −0.10)가 CoM sweep 을 개선해도, 그게 실물 전이 실패를 줄인다는 인과가 있나 없나?
4. 지금(사람 부재, 실물 시험 불가, GPU 가용) 12:30까지 자율로 할 때 **가장 기대값 높은 작업 순서**는? (a) v6 CoM 반복학습 (b) 케이블 모델 구축+ v5 재현 게이트 (c) 절차/계측 코드·문서 (d) 기타.
출력: 항목별 판정·근거, 400~700단어, 파일 만들지 말고 출력.

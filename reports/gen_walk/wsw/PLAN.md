# WSW 사전 기록 (1005, 보행 트랙) — 서기(G21a) ↔ 걷기(W2-8) 전환 평가

배경(WFALL): W2-8 보행 평가의 낙상 ~8 %는 거의 전부 걷기 명령 전 서기 구간(스폰 착지 과도)이다. 걷기 중 낙상은 그룹당 0–3/150이다.
실제 시스템은 G21a 서기에서 걷기를 시작한다 → 전환 자체를 잰다.
- 구성: 서기 구간 G21a-11300 → 걷기 명령 시점 W2-8 24791 인계 → 정지 명령 뒤 0.5 s 에 G21a 로 복귀. 배포 조건(보조 α1 + HeadingHold 1), 지연 3, seed 1·2, n 600(그룹 150).
- 대조: WFALL(W2-8 단독, 같은 조건).
- 지표: 낙상 시점 4구간(서기/걷기 시작 1.5 s/정상/정지 뒤), 정지 정착 시간, 정지 뒤 피치 p2p, 요·옆 표류.
- 판정(사전): 걷기 시작 1.5 s 낙상 ≤ 1 %, 정지 뒤 낙상 ≤ 1 %, 서기 구간 낙상이 WFALL보다 적음 → 전환 구조 통과. 정지 정착 ≤ 1.0 s 를 목표로 본다.

# W2-9 가설 (1004, 학습 전 기록)
- 관찰: 요 명령은 관측에 정상 전달(cmd_probe), 보상 수정 5회·모방 끔(W2-8)에도 회전 추종비 ≈ 0. 개루프 보조(스윙 힙 회전 κ·wz)를 W2-8 정책에 걸면 걷기를 유지하며 크게 회전(|추종비| α2 0.57, 낙상 3 % 불변) → 물리적으로 회전 가능, **탐색 실패**.
- 가설: STEP primitive(A0m) 때처럼 보조로 회전 경험을 주고 α 를 0 까지 감쇠하면 정책이 회전 명령 추종을 스스로 익힌다.
- 변경(W2-8 대비): 회전 보조 1개 — 스윙 힙 회전 += α·κ·wz(κ −0.455, 스윙 상승·지지 복귀, 6틱 앞당김), α 2.0→1.5→1.0→0.5→0.25→0(블록 회전 추종비 ≥ 0.5 & 체류 50 반복). 보상 불변. 출발 W2-8 마지막(24791), 2000 반복.
- 성공 기준(α = 0 도달 체크포인트, W2-8 과 같은 eval):
  1) 상수 요 명령 추종비(±0.15·±0.30, vx 0.10) 부호 일치 & 평균 ≥ 0.5
  2) HeadingHold kp 1.0 요 표류 < 5° (vx 0.05–0.15)
  3) 보행 유지: 추종 오차 ≤ 0.05(0.15 m/s 는 W2-8 0.061 대비 악화 없음)·낙상 ≤ 10 %·교대 ≥ 70 %·좌우 착지 40–60 %
- fail-fast: 2000 반복 안에 α ≤ 0.5 도달 못 함 → 보조 의존(감쇠 실패) → 감쇠 규칙(추종비 문턱) 분석.
- α = 0 에서 회전 소실 → 보조 의존 → missed-turn 류 벌점(A0m 방식) 1개 추가 검토.
- 이 결과는 보행 축 전용 — C5 회복 축과 섞지 않는다.

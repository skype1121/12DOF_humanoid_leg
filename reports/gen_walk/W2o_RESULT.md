# W2o 결과 (1005) — 사건 보상 제거: 500에서 속도 신호, 1000에서 보행 붕괴(정지 학습) → 중단

배포 조건, 지연 3, seed 1, 그룹 n 80. (정정: 500 반복 자동 평가는 체크포인트 이름 오류(25291 대기, 실제 저장 25300) 로 돌지 않아 학습이 1500까지 갔다 — 사후 평가.)
| 체크포인트 | 실제 속도(명령 .05/.10/.15) | 낙상 | 교대 |
|---|---|---|---|
| 24791(W2-8) | 0.089/0.094/0.096 | 4–6 % | 94 |
| 25300(+500) | 0.048/0.068/0.072 | 5–9 % | 89–94 |
| 25800(+1000) | 0.003/0.006/0.006 | 5–11 % | 31–52(보행 소실) |
- 500에서 처음으로 명령 의존 속도가 나왔다(기울기 ~0.24). 이어 학습이 '걷지 않기'로 수렴했다.
- 구조 해석: 사건 보상이 있으면 고정 보폭 국소해, 없으면 저속 범위(0.05–0.20)에서 속도 추종 보상(std 0.1)이 정지와 보행을 충분히 가르지 못해(정지도 37–78 % 획득) 정지가 이긴다.
  → 보상만으로 '속도가 중요'해지지 않는다. **다음 = 명령–보행 주기(클록 주파수) 연결 구조**(사건 보상 유지, cadence 로 속도 조절). 배포 계약(브리지 클록 위상 적분) 변경 후보.

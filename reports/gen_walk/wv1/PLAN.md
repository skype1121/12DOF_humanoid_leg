# WV 토너먼트 사전 기록 (1005, 보행 트랙) — 속도 추종

WVEL(W2-8, 배포 조건, 지연 3): 명령 0.05/0.10/0.15/0.20 → 실제 0.089/0.094/0.096/0.097 m/s. **속도 추종 기울기 ≈ 0.05.**
- 가설: sb0 스텝 모드 보상이 고정 보폭(진행 5 cm 포화, 유효 착지 3–10 cm)과 고정 클록 1.1 Hz로 한 가지 걸음만 정의한다.
- WV1 = W2v: 진행 포화·착지 창을 stride = |vx|/(2·1.1) 기준으로 비례시킨다(단일 구조 변경). 안전 PPO, 400 반복, 부모 W2-8 24791.
- 대조 = WT0(W2hSafe, 같은 부모·400 반복, 25190).
- 평가: 배포 조건(W2i 보조 α1 + HeadingHold 1), 지연 3, seed 1·2, n 400, vx 0.05/0.10/0.15/0.20, 평균 전진속도·기울기.
- 판정(사전): 실제 속도 대 명령 기울기 ≥ 0.5(대조 ≈ 0.05) + 걷기 중 낙상 ≤ 대조 + 2 %p + 교대 ≥ 90 % + 요 표류 ≤ 10° → 채택 후보, 장기 학습(1500 반복) 검토.
  기울기 < 0.2 → 보상 기준 비례만으로는 부족하다. 다음 구조 후보는 클록 주파수 명령 연동 또는 명령 관측 스케일.

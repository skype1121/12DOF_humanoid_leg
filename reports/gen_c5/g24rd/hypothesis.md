# G24R-d 가설 (1004, 학습 전 기록) — C5 회복 정책 후보
- 관찰: C5 기본 판정 — 서기·전환 통과, 미달 = sf12 12.0 %(8 seed)·sf15 31.8 %. 인계 A/B/C 불일치 근거 없음 → 회복 정책 성능 문제.
  G24R-a 학습 외란 R3 = 앞 10–12 N 램프(상승 1–4 s) — 평가 sf15(15 N)는 범위 밖, sf12 는 상단.
- 가설: 앞 12–15 N 연습(R4)으로 회복 정책의 강한 앞 밀기 회복이 좋아진다.
- 변경(G24R-a 대비): 외란 단계 R3 → R4 고정 1개. 보상·관측 불변. 출발 G24R-a-21793, 1500 반복.
- 평가: C5 안에서(G21a + G24R-d, 감지기 동일) 같은 경로 짝 비교 vs C5 기본(c5b). sf12 seed 1–8, sf10·sf15·b18·sb10·nd·d3nd seed 1–4.
- 성공 기준(C5_PLAN_CRITERIA 회복 항목 + 비퇴보): sf12 ≤ 8 %(목표 6), sf15 ≤ 30 %, sf10 ≤ 5 %, b18 ≤ 2 %, 그리고 서기·전환 기준 유지(nd ≤ 2.3·d3nd 비유의·오탐 < 2 %·재발산 < 2 %).
- 실패 분기: sf15 개선 & sf12 불변 → 상승 속도(평가 0.5 s vs 학습 1–4 s) 불일치 검토(다음 단일 변경 = 상승 시간 범위). 둘 다 불변 → 회복 정책 용량/관측 한계 검토.

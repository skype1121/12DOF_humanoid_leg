## 구조
COMMAND(vx,vy,wz) + gait_enable → 위상 생성기 → (명령 조건) 착지 목표 / 참조 → RL 잔차 → 관절 목표(기존 배포 체인: 슬루 → LPF → 지연).
- **gait_enable**: 0 = STAND(클록 관측 (0,0)), 1 = STEP(클록 sin/cos(2πφ) 회전; φ 0–0.5 왼 스윙, 0.5–1 오른 스윙).
  - 1 + 명령 0 = 제자리 교대. 1 + 명령 ≠ 0 = 명령 조건 이동.
  - 관측 차원 불변(클록 2채널의 의미만 변경). **배포 계약 변경**.
  - 사전 점검: G21a가 클록 (0,0)에서도 서는지(W2omF 붕괴 교훈).
- **cadence**: Stage 0은 1.1 Hz 고정. 이후 f = clamp(0.9 + k·‖v‖, …)는 prior일 뿐이다.
  체인(명령 → 위상 주파수 → 유효 cadence → 보폭 → 속도)을 측정한다.
- **착지 목표**(몸통 요 프레임, 스윙발): p* = p_nominal(좌우 기본 폭) + (vx, vy)·T_step/2 + 요 회전 성분. Stage 0은 p* = p_nominal(제자리).
- **참조(W3-C)**: q_ref(φ, cmd) = 스윙발 굽힘 펄스(A0h ref_step_primitive_flex) + **관상면 무게 이동**(지지발 쪽 hip_a·ankle_r, 이륙 약 0.1주기 앞) + 명령 오프셋(이후 단계).
  - q_target = default + q_ref + δq_policy. 잔차 크기는 처음에 제한한다.
- **보조(scaffold)**: 굽힘 펄스 강화 α_s(감쇠, 절대 문턱). 최종 평가는 α_s = 0.
  W3-C는 참조가 제어기 일부지만 **참조 0 평가도 같이 보고한다**(자립 진단).

## 보상(새로 설계, gait_enable로 분리)
- STAND(ge 0): G21a 서기 보상 세트(그대로).
- STEP(ge 1):
  - TASK
    - 주기 접촉: 스윙 구간 −F_swing/mg, 지지 구간 −|v_foot|.
    - 스윙 발 높이 추종 exp(−(z − z_ref)²/σ²).
    - 착지 목표 추종(착지 사건: exp(−‖p_td − p*‖²/σ²)).
    - 속도·요 추종은 ‖cmd‖ > 문턱일 때만.
  - STEP QUALITY
    - 유효 스텝 사건(이륙 ≥ 60 ms·≥ 1.5 cm → 착지 → 0.3 s 안 하중 ≥ 0.5 mg 0.1 s).
    - 교대(예정 발).
    - 놓친 스텝 벌점.
  - STABILITY: 기울기·높이·ω_xy·종료 벌점.
  - REG: 행동 변화율·관절 가속·토크·관절 한계.
  - 생존 보너스는 STAND만 받는다. **STEP에서 가만히 서면 총점 ≤ 0**(주기 접촉 벌점).
- 사건 보상의 초당 기여 ≤ TASK 연속 항의 50 %(발만 들면 고득점 금지).

## 학습 전 단위시험(reward_landscape.py)
- 서기 궤적 × {STAND, STEP0, FWD, BACK, LATL, LATR, YAWL, YAWR}: STEP 모드 전부 STAND보다 낮고 ≤ 0.
- 개루프 참조 걸음 궤적(α 1, 정책 G21a): STEP0에서 서기보다 명확히 높아야 한다(≥ +2/s).

## Stage 0 토너먼트(300–500 반복, G21a 출발, seed 1, 외란 없음)
- W3-A: 위상 + 새 보상 + 굽힘 보조 scaffold(감쇠).
- W3-B: A + 착지 목표 관측(4차원/프레임, 입력 확장 0 초기화).
- W3-C: A + 참조 잔차(굽힘 + 무게 이동).
- 판정(보조 0 평가, 제자리 120 s 장시간 포함):
  - 교대 > 90 %, 이륙 / 착지 > 90 %, 하중 수용 ≥ 85 %, 낙상 < 5 %.
  - 수평 표류 ≤ 0.03 m/s, 장시간 붕괴 없음.
  - 보조·참조 기여 기록.

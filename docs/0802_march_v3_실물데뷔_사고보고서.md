## 실측으로 확정한 사실

1. **AK 모터 명령 타임아웃 ≈ 200~300ms** (기존 추정 "수 분" 폐기). 타임아웃 시
   완전 릴리즈가 아니라 **브레이크(감쇠) 모드** — 손으로 만지면 뻣뻣하지만
   하중 자세는 못 지킴. → **하중 지지 중 스트리밍 침묵 = 수백 ms 내 붕괴.**
2. **인수 공백의 태반은 소프트웨어 비용** — python-can 임포트+소켓 오픈.
   대기 중 선오픈으로 303ms→20-40ms.
3. **arb_id 폴백 오귀속** — 명령 프레임(data[0]=위치 상위바이트)이 피드백으로
   삼켜져 ±수백° 유령 관절각 생성. 형상검증(data[0]==arb∈1..12)으로 박멸.
4. **파이프라인 루프 지연 80~160ms(4~8틱)** — sysid 실측. 명령경로 2~3틱 +
   관측경로 2틱. 학습 DR은 명령 지연 0~2틱만, 관측 지연은 0이었다.
5. **관절별 유효 추종비 0.17~0.97** — 무릎 0.27, 발목롤 ~0. DR 강성 하한
   0.4는 낙관이었다.
6. **리플레이 대조**: 실물에서 녹화된 명령 시퀀스는 시뮬 물리에서도 0.9s에
   낙상 — 정책이 실물 관측 스트림에서 이미 나쁜 액션을 냈다는 뜻.
   관측 갭(지연·접촉·기울기)이 1차 문제.

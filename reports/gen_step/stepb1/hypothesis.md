# STEP-B1 가설 (1004, 학습 전 기록)
- 관찰: STEP-B0 load_transfer 보상이 1500 반복 내내 평탄(0.011–0.014, 최대치 ~0.4 %), 스윙·착지 보상 0. 첫 비대칭 하중조차 탐색 안 됨.
- 가설 H-B1: 곱형 하중 보상(ramp × ramp)은 대칭 서기(0.5/0.5 mg) 근처에서 기울기가 0 이라 탐색이 시작되지 않는다. 선형 비대칭 보상이면 즉시 기울기가 생겨 비대칭 하중이 증가한다.
- 변경 변수: 하중 보상 형태 1개(가중치 2.0·창 동일). 기타 STEP-B0 그대로.
- 성공 기준(fail-fast, eval_step, 스텝 모드 vx 0.05·지연 1): 반복 200/400/600(ckpt 11500/11700/11900) 중 400–600 에서
  ① 전환 구간 하중 비대칭 평균이 기준선(STEP-B0 최종·G21a) 대비 +0.05 mg 이상 증가 또는 ② load_ready ≥ 5 % 또는 ③ valid 이륙 ≥ 기준선 + 5 %p.
  하나라도 만족 → 학습 계속(1500 반복) 뒤 최종 평가(STEPB0_CRITERIA 1·2). 셋 다 불만족 → 구조적 실패, 학습 중단.
- 실패 시 분기: Case A(비대칭 불변) → NEXT 2 시연/모방 부트스트랩. Case B(load_ready↑ 이륙 없음) → 스윙 부트스트랩. Case C/D 는 지시서 규칙.

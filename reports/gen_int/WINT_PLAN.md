# WINT 사전 기록 (1005, 통합 1단계) — 걷기 중 외란 → 회복 정책 → 서기 래치

배경: 걷기 중 앞 밀기가 최약점(WPUSH)이다. 서기 감지기 문턱(3°/0.5)은 정상 보행에서 93 % 오탐한다(WINT 스모크).
보행 주기 저역(τ 0.45 s) 기울기 편차는 정상 보행 99 %가 4.0–4.2°이고, 밀기 중앙값은 3.3–6.1°다(WMONF).
- 구성: G21a(서기) → W2-8(걷기, 보조 α1+HH) → [감지: 걷기 중 저역 편차 > 4.5°, 서기 구간은 RV4] → G24R-a 21793(+ki cue·조기 복귀) → G21a 래치.
- 조건: 지연 3, seed 1, n 400, 무외란·sf8·sf12·fi40·b18. 대조 = 같은 seed 걷기 단독(WPUSH·WSTOP 0.5).
- 판정(사전): 무외란 오탐 ≤ 2 %, 무외란 낙상 비퇴보(+2 %p), 밀기 조건 걷기 구간 낙상이 대조 대비 유의 감소 → 통합 감지 구조 유망.

## 0. 이 문서의 규칙 (먼저 읽을 것)

| 태그 | 뜻 |
|---|---|
| **MEASURED** | 원시 로그 필드에서 직접 읽은 값 |
| **COMPUTED** | 로그 값에서 명시된 공식으로 유도한 값 (공식을 항상 적음) |
| **HYPOTHESIS** | 해석. 구별 불가능한 설명이 여럿이면 **전부 남긴다** |

- **압력 패드는 접지 판정 전용**이다. 이 문서에서 `foot_n` / `pct` / `raw_sum` / CoP / 좌우 하중비를 **하중으로 쓰지 않았다**. 접지 비트(`contact[2]`)만 조건 분류에 썼고, 패드 유래 수치가 나오는 곳에는 `미보정 진단값(uncalibrated diagnostic)`을 붙였다.
- **관절 배열은 이름으로 매칭했다.** `targets_deg_joint`/`targets_deg_motor`는 관절명 dict, `qpos_rad`/`qvel_rad_s`/`tau_est_nm`/`raw_action`은 `JOINT_ORDER`(좌우 교대) 리스트. 두 표현을 섞은 곳은 전부 이름 기준으로 재매핑했다.
- **모터측 추종·토크에서 구조 강성·엔코더 하류 변형·발 미끄러짐을 결론짓지 않는다.** 이 문서는 그 어떤 것도 주장하지 않는다(§12).
- **적합(fit)과 검증(validation)은 시험 단위로 분리**했다. 프레임 셔플 없음. 한 trial 로 적합하고 **다른 trial** 을 예측했다.

## 2. 프레임과 정의 (코드로 확인)

```
stage8 (jetson/scripts/stage8_12axis_mit_control_node.py)
  CONTROL_PERIOD_SEC = 0.02   (50 Hz 제어 타이머)
  STATUS_PERIOD_SEC  = 0.01   (100 Hz status 발행)
  MAX_TARGET_STEP_DEG_PER_TICK = 4.0   (틱당 슬루 = 200 °/s)
  cmd ← _step_toward(cmd, des)   # des 로 틱당 ≤4° 접근
  CAN 프레임 p_des = radians(base + cmd)

프레임 (jetson/scripts/rl_bridge_node.py FrameMap — 하드웨어맵 단일 원본)
  joint_rad      = radians( DIR × (motor_deg − SZ) )
  motor_deg      = SZ + DIR × degrees(joint_rad)
```

정의 (이 문서 전체에서 고정):

| 기호 | 정의 | 태그 |
|---|---|---|
| `u_stage8` | `cmd` (모터프레임 상대 deg) | MEASURED |
| `y_stage8` | `act − base` (모터프레임 상대 deg) | **COMPUTED** |
| `e_stage8` | `cmd − (act − base)` — `stiffness_log.analyze` 와 동일 규약 | **COMPUTED** |
| `u_bridge` | `targets_deg_joint[j]` (관절프레임 deg, LPF 후·블렌딩 **전** 정책 목표) | MEASURED |
| `y_bridge` | `degrees(qpos_rad[i])` (관절프레임 deg) | **COMPUTED** |
| `e_bridge` | `u_bridge − y_bridge` | **COMPUTED** |
| 운동 문턱 | 1 s 창에서 `|u(k) − u(k−W)| > 1.0°`, `W = round(1 s/dt)`. 판정된 구간은 앞쪽 W 샘플까지 포함. 세그먼트 최소 길이 1 s, 세그먼트 내 `std(u) ≥ 0.15°` | **COMPUTED** |
| 정지(quiet) 창 | 1 s 창에서 `ptp(u) < 0.10°` **그리고** 운동 마스크 아님 | **COMPUTED** |

`blend_alpha < 0.999` 인 틱은 `targets_deg_motor` 가 블렌딩되어 `targets_deg_joint` 와 달라지므로 **전 분석에서 제외**했다.

## 8. 명령 반전 시 데드밴드·마찰 징후

방법(**COMPUTED**): 명령 `u` 의 국소 극값(앞 0.30 s·뒤 0.60 s 창의 argmax/argmin 이 그 점)에서, 좌우 진폭이 모두 ≥0.30° 인 것만 반전으로 채택. 각 반전에서
- `meas_lag` = 실제 `y` 가 같은 방향으로 꺾이는 데 걸린 틱,

## 12. 이 문서가 **말하지 않는** 것 (명시적 금지선)

- **엔코더 하류 변형·구조 강성·감속기 처짐에 대해 아무것도 주장하지 않는다.** 여기 쓰인 `act`/`qpos` 는 전부 **로터(모터측) 절대각**이고, 모터측 추종오차가 작다는 것은 **모터측이 목표를 따라갔다**는 뜻일 뿐 그 하류에서 무슨 일이 있었는지 말하지 않는다.
- **`tau_est` 회귀로 강성을 추정하지 않았다.** (§4의 `|tau|` 최대값은 신호 특성 서술일 뿐이다.)
- **발 미끄러짐·CoP·CoM 에 대해 아무것도 주장하지 않는다.** 패드는 접지 비트로만 썼다.
- **낙상 원인·자세 편향의 원인을 주장하지 않는다.** §7.2의 정지 오차 부호는 세 가지 설명이 구별되지 않은 채로 남아 있다.
- **`jetson/calib_data/` E0 에폭 값과 병합하지 않았다.** 발목 리마운트 이전이라 경계가 다르다.

## 0. 결론
1. **아침 실물 정책 = G12-9500** — G16 5개 학습(G16o ×2·G16a ×2(1개 중단)·G16d) 모두 사전 기준 탈락(§5).
2. **결정 필요(승윤님)**: 관측 EMA 모드 — (A) 현재 러너 그대로 / (B) `stand_crouch_g12_ema0`(학습 계약 복원). 배포는 스크립트 1개(§2), 젯슨 미배포 상태.
3. **시뮬 기대치**: 짧은 지연(0–6틱)에서 무외란 낙상 ≤0.6 %·흔들림 ≤1.6 %(§4). 시뮬은 0929 실물 흔들림 성장을 재현한 적이 없으므로
   오늘 실측(지연·흔들림)이 곧 다음 설계 입력이다.
4. 현장 확인 필요: stage8 수정 뒤 명령 경로 지연(s8_cmd)·목표→관절 응답 지연·흔들림 여부 / 미검증: ema0 모드의 실물 동작.

## 1. 젯슨에 이미 배포된 것 (0930, 실물 미검증)
- stage8 명령 적체 수정(dof12_mapping 캐시, 1e31a27): 벤치 50/s·발행→CAN 10–20 ms — **현장 확인 필요**(명령→관절 지연이 320 ms → ~100 ms 로 줄었는지).
- stage8 명령 계측(e133b2c): 블랙박스 `s8_cmd`(발행→처리 나이·누락·출처), 브리지 센서 구독 최신값 1칸(114b644).

## 2. 아침에 결정할 것 — 관측 joint_vel_ema 계약 (준비 완료, **젯슨 미배포**)
- 발견: G4~G15 는 학습 중 이 채널(관측 60/320)이 0+잡음이었는데, 실물 러너는 실제 속도 EMA 를 넣어 왔다.
- 시뮬 대조(G12-9500, 같은 초기조건 311쌍): 무외란·8 N 동일 / 뒤 18 N 낙상 44.7(학습 계약) vs 52.1 %(실물형), p=0.019.
- 0929 로그 재생: 조용한 구간 명령 차이 ≤0.11°, 2 Hz 큰 흔들림 구간 발목롤 22° RMS(속도와 무상관).
- ema0 모드 그대로 시뮬(eval seed 1–3, 뒤 18 N 낙상): d3 ema0 45.5 % ≈ 학습 계약 44.7 % < v2 52.1 % / **d1 ema0 60.4 % ≈ v2 61.1 %**.
  관절 상태 3틱 샘플홀드와 겹쳐도 무외란·8 N 은 두 모드 같음. → **실측 지연이 짧으면(d≈1) 시뮬상 EMA 모드 차이는 거의 없다**; 차이는 지연 3 이상 큰 밀기에서.
  (ema0 평가는 난수 소비가 달라 DR 표본 짝이 아님 — 독립 표본 비교)
- 선택지(콘솔 드롭다운):
  - `stand_crouch_g12` = 0929 과 같은 동작(실제 EMA) → 지연 수정 효과만 보는 깨끗한 대조
  - `stand_crouch_g12_ema0` = 학습 계약 복원(EMA 0)
  - 제안: 두 번 이상 시험하면 **A(g12) → B(g12_ema0)** 순서. 1회로는 통계 판정 불가.
- 배포: `deploy/deploy_ema0_1001.sh` (점검만) → `--apply` (백업·md5·젯슨 selftest) → 드롭다운 표시엔 `--restart-console`
  (센서가 떠 있으면 재기동 거부 — 콘솔에서 정리 후). 되돌리기 = `.bak_1001`. **오프라인 검증 완료**(러너·브리지·콘솔 selftest, 로그 재생).

### 4-1. 관절 상태 샘플홀드 평가 (시뮬, G12-9500, eval seed 1–2) — 오프라인 검증 완료
- 0929 실물 로그에서 관절값이 직전 틱과 같은 비율이 72 %(명령이 움직일 때 44 %)라, 브리지와 같은 추정기(값이 그대로면 속도 0, 바뀌면 Δq/(틱×머문 틱))로
  관절값을 2틱·3틱에 한 번만 갱신하도록 모사했다.
- 결과: 지연 1·3 무외란·뒤 8 N 모두 **매 틱 갱신과 사실상 같다**(낙상 0–0.5 %, 흔들림 지속 0–1.9 %, 부호반전·action-rate 동일).
  → 시뮬 기준으로 관절 상태 샘플홀드(2–3틱)는 0929 흔들림의 원인 후보에서 뺀다. 아침 로그의 갱신 누락률은 기록용으로만 본다.

### 4-2. OSC 재현 v2 A/B (시뮬, G12-9500, 지연 11·14 × 무외란·앞 8 N·뒤 8 N, eval seed 1–3) — 사전 판정 '미지지'
- 관측만 legacy ↔ v2(실물형 EMA)로 바꿔도 0929 실물 서명(2 Hz·p2p>2°)은 **둘 다 0** env, 양발 접촉 100 %, 128 env 집계도 같은 급
  (osc_sig_result.txt). → 현 시뮬 플랜트에서는 EMA 계약 불일치만으로 실물 2 Hz 흔들림이 재현되지 않는다. 시뮬 흔들림이 작아 EMA 가 학습 분포 안에 머물기 때문일 수 있다.

## 2. 무엇을 바꿨나 (아키텍처)

1. **관측 45 → 245차원**: 단일 프레임 → 49차원 × 이력 5스택 (Lee 2020) —
   접촉·지연 등 부분관측 보완. 게이트 클록(sin/cos 1.4Hz)과 발바닥 접촉
   2ch(RA30P 힘센서 대응, >5N 이진) 추가.
2. **주기 보상 (Siekmann 2021)**: 클록 위상-접촉 일치 보상으로 걸음 리듬을
   구조적으로 강제 — 기존의 벌점 패치식 대칭 교정(3회 연속 보상 게이밍으로
   실패)을 대체. 좌우 절뚝임의 근본 해결책.
3. **미러 대칭 로스 (Yu 2018)**: rsl_rl 네이티브 symmetry — 좌우 스왑 미러
   변환으로 대칭 걸음을 학습 단계에서 형성.
4. **명령 분포 명시 샘플링**: 제자리회전 15%·후진 15% 강제 배정 + 접지
   요-슬립 벌점 — "비벼서 도는" sim2real 함정 차단.
5. **헤딩 폐루프 (신규 상위 계층)**: IMU 요 → wz 명령 P제어 (kp1.0, ±0.6
   제한, 랩어라운드 처리). 정책 밖 명령 계층이라 재학습 없이 이식 가능.
6. **방폭 체계**: 관측 클리핑(NaN 크래시 5회의 확정 해결책) + 보상 캡핑 +
   솔버 12/2 — 이후 전체 학습 캠페인 크래시 0.

## 3. 개선 과정 (4라운드 반복 + 판정 원칙)

- **R1(v2)**: 회전·후진·곡선·경사 4항목 학습 도입 → 판정: 회전량 미달 등 부족항목 5건
- **R2**: 요 추종 가중 강화 → 관절속도 −65%, 산식 오인 교정(케이던스 채터 함정)
- **R3**: 자세 안정화 + 헤딩 폐루프 구현 + 경사 지형 보강 (적대 리뷰로 지형
  양자화 결함 사전 차단) → p95 회복, 경사 고난도 25→19%
- **R4**: 발 간격 확폭 18→22cm (측면 푸시 A/B로 검증) → 뒤뚱 비용 없이
  발목 마진 2배
- **판정 원칙**: 심투리얼 실물이식 안정성 1순위 — 시뮬 성능보다 외란 강건성·
  액추에이터 마진·자세 마진 우선. 낙상률 판정은 64env 이상(소표본 노이즈 함정).

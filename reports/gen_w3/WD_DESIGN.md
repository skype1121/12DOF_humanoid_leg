## 3. 보상(가산만 — 기존 걷기 항은 외란 구간에도 그대로)
| 항(가중, 단위 = 기존 W3 항과 같음) | 정의 | 무외란 env |
|---|---|---|
| `w3d_cap`(10) | 회복 착지(충격 시작 ~ +1.2 s, 최대 3 착지)마다 포획 차분형 v2 `cap_df` = clip((Φ_전 − Φ_후)/5 cm, 0, 1), Φ = max(0, dist(ξ_eq, 지지영역) − 1 cm), 전 = 직전 양발 지지영역(c2 v2 와 같은 함수) | 0 |
| `w3d_rplace`(10 = `w3_place`) | 회복 착지마다 max(0, gain − place_명목) → 착지 항 = max(명목, gain) | 0 |
| `w3d_rstride`(10 = `w3_stride`) | 회복 착지마다 max(0, gain·s_max − stride_명목) → 보폭 항 = max(명목, gain·명목 최대점) | 0 |
| `w3d_ret`(20, 1 회/외란) | 외란 끝 + 0.3 s 뒤 **외란 전 같은 env 기준(EMA τ 2 s) 대비** 주기 평균 속도 오차 ≤ 전 + 0.03·기울기 ≤ 전 + 2°·\|ω_xy\| ≤ 1.5·전 + 0.05(eval_w3 WALK 판정과 같은 꼴)가 0.5 s → max(0, 1 − (t − t_on)/4 s) | 0 |
| `w3d_sret`(20, 1 회/외란, 정지 시나리오) | 래치(ge 0) 뒤 양발·기울기 < 3°·\|ω_xy\| < 0.2·\|v\| < 0.08 가 0.5 s → max(0, 1 − (t − t_stop)/4 s) | 0 |

- `gain` = clip((Φ_명목착지 − Φ_실제)/1 cm, 0, 1): 같은 순간 W3 명목 착지 목표(반폭 0.144)에 디뎠을 때보다 실제 착지가 더 포획했는가.
  1 차 설계(보전 = cap_df)는 단위시험에서 **부분 포획 개선(cap_df 0.2) 시 방향 회복 스텝이 원래 보폭보다 손해**(뒤 밀기 −0.12)여서 교체했다.
- 왜 보전이 필요한가: 새 항 없이 W3S3d 보상으로 채점하면 방향 회복 착지 0.742 < 원래 보폭 1.000(앞 밀기, [B] 참고줄) — **기존 걷기 보상은 회복 스텝을 벌한다**.
- 숨기 유인: 모드(ge)는 명령 시간 규칙만 바꾸고 회복 창은 실제 외란 시각으로만 열린다 → 정책이 상태로 창·정지 시점을 조작할 수 없다(c2 의 상태 조건 정지 유인 제거).
  얼어붙기(스텝 중단)는 기존 놓친 반주기 −10·주기 접촉 벌점이 막는다. 복귀 1 회 보상은 외란 단위·시간 감소형(빨리 정상으로 가는 쪽이 이득, 외란 없이는 0).
- 의도적 제외: 초과 스텝 벌점(1006 결정), 새 정숙 보상(G15: 정숙 보상이 회복 낙상 악화), 회복 중 회전 착지 보전(`w3_turn_stride`, 회전+외란 동시는 1 차 범위 밖).
- 알려진 기존 결함(이번에 바꾸지 않음): W3 `w3_place` 명목 반폭 0.10(실제 0.144–0.18) → 옆 밀기에서 안쪽(반대) 착지가 착지 항으로 이득. 폭 벌점 `w3_width`(−10)가 있어야 순위가 맞는다([B] 왼쪽 행, 폭 벌점 빼면 반대 > 원래).

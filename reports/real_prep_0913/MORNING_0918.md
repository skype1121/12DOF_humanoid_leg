# 아침 보고 — 0918 (밤 자율 작업 결과)

## 한 줄
손 튜닝 크라우치 자세를 기본자세로 한 **정책 stand_crouch_v1**(그리고 계속 학습 중인 v1b)을 만들고 젯슨에 올렸습니다.
시뮬 판정은 **미승격**(명목 36 %·DR 7 %)이지만, 같은 크라우치 출발에서 **옛 정책 v6 는 1 %·고정 홀드 0 %** 라 상대 우위는 큽니다.
콘솔엔 **자동 수평** 모드가 붙었고, 아침 시험은 `robotctl` 6줄로 됩니다(아래).

## 1. 콘솔·도구 (젯슨 반영·재시작 완료, 실물 조작 없음)
- **자동 수평**(auto level): 접지·kp150·IMU 조건에서 fwd→0° 로 힙앞뒤 트림 0.5°/s·±10° 자동 조정. 접촉 없음/편차 8° 초과면 일시정지. 버튼·`robotctl autolevel on/off`.
  근거: 같은 관절각인데 착지마다 몸통 −1~+9° 로 달라 앞뒤 여유가 뒤집힘(0917).
- `robotctl config air|ground [ckpt]`, `robotctl handoff`(자동수평 끔→인계→기준점→ARM→정책 로드, 단계별 응답 대기), `robotctl stand`.
- 왼발 패드 1개 탈락 → 접촉 [0,1] 잦음 → **시험 방식 air 권장**, 패드 재부착이 최선(정책 입력 오염).

## 2. 정책 stand_crouch_v1 (S9c 환경)
- 환경: 기본자세 = 크라우치 v3(힙 ±15·무릎 ∓30·발목앞뒤 ±20.5) + **env 별 물리 기본자세 편향 DR**(힙 ±12°·무릎 ±5°·발목 ±8° = 실물 영점/사슬 오프셋의 시뮬 등가) + 스폰 피치 ±8° + 지면 연성 k2e3 + S8ac4r DR 상속. v6 웜스타트 +3000it(model_144485). 보상 44→53·에피소드 길이 517 로 아직 상승 중이라 **+6000it 계속 학습(v1b) 진행**.
- 배포 계약 변경: 체크포인트별 기본자세(`CKPT_DEFAULT_POSE`, 러너 `default_pose_rad`). 젯슨 브리지 selftest ALL PASS(계약 검사에 env.yaml 기본자세 일치 포함).

## 3. 아침 시험 순서 (실물)
```
robotctl config air stand_crouch_v1     # (v1b 가 더 좋으면 v1b)
robotctl prep                            # 영점 어긋나면 zero-fix → prep
robotctl hang -y ; robotctl level        # v4 자세로 공중 → 줄로 착지
robotctl ground ; robotctl autolevel on  # 수평 잡힘 확인 (status 에 '자동수평 수평')
robotctl handoff ; robotctl stand        # 인계 → 정책. 줄 느슨·손 떼기. watch 로 관찰, 문제 시 estop
```
정책이 실물에서도 크라우치를 유지하며 서면 성공, 곧은 다리로 펴며 뒤로 가면 옛 실패 재현(그땐 v1b/재학습 근거).

## 4. 남은 위험
- 시뮬 절대 성공률 낮음(명목 36 %) — 실물이 시뮬보다 관대한 면(홀드 2분 자립)이 있지만 보장 아님. 줄 필수.
- 왼발 패드 탈락(접촉 비트), 왼 무릎(모터4) 전환 순간 버클 이력(핸드오프 시 15° 이탈 가드).
- 지면 연성·편향 DR 범위는 가정값(스윕 미완료). 스윕(pitch_sweep.py, 힙 20 근처 자세에서)이 되면 DR 을 실측 범위로 좁혀 재학습.

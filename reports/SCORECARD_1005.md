# 고정 Regression Scorecard (1005, 최종 후보 판정용 — 결과 보기 전 고정)

모든 주요 후보는 같은 시험을 통과해야 한다. 강도는 현재 failure envelope 기준이다. 능력을 숨기려 항목을 빼거나 기준을 바꾸지 않는다.
공통: 짝 비교(같은 DR 표본, fall_pool 자동 검증), 평가 seed 1–4(회복)·1–2(보행), 인접 체크포인트 ≥ 2개.

## A. 서기·회복 (STAND + RECOVERY + SWITCHING, eval_ground_recovery / eval17)
| 영역 | 조건(태그) | 지연 | 기준(후보 vs 대조 C5) |
|---|---|---|---|
| STAND | nd (무외란 서기) | 3·4 | 낙상 ≤ 1 %, 오탐(켜짐) ≤ 대조 +3 %p |
| DELAY | 위 전부를 지연 3·4 에서 | 3·4 | 지연 4 에서도 아래 기준 |
| RAMP | sf15 (앞 램프 15 N) | 3·4 | 대조 대비 비퇴보, 개선이면 가점 |
| IMPULSE | fi40 (앞 40 N·0.2 s) · fs80 (앞 80 N·0.1 s) | 3·4 | 비퇴보 |
| BACK | b18 (뒤 18 N·0.3 s) | 3·4 | +3 %p 이내 |
| PAD FAULT | pdnd · pdsf12 (L 패드 0 고착) | 3 | 비퇴보 |
| HIP-ZERO | 신전 1.5° · 굴곡 1.5° × (sf15·b18·nd) | 3 | 비퇴보 |
| SETTLE | 생존 env 정착 중앙(회복 모드 해제까지), 최종 정숙 | 3·4 | 대조 이하 |
| SWITCHING | 외란 뒤 재켜짐 % · 켜짐 ≥ 2 env(nd) | 3·4 | 재켜짐 ≤ 20 %, nd 채터 ≤ 3 env |

| CKPT | 인접 체크포인트 21700(21793 기준) | 4 | 같은 방향 재현 |

## B. 보행 (WALK, eval_walk, 배포 조건 = 보조 α1 + HeadingHold 1 + G21a 전환)
| 영역 | 조건 | 지연 | 기준 |
|---|---|---|---|
| WALK | 무외란 vx 0.05/0.10/0.15/0.20, n 80–150/그룹 | 3 (+1·4) | 걷기 구간 낙상 ≤ 5 %, 교대 ≥ 90 %, 유효 스텝 ≥ 95 % |
| WALK→STAND | 정지 뒤 낙상·정착(G21a 인계 0.5 s) | 3 | 정지 뒤 낙상 ≤ 1 % |
| STAND→WALK | 걷기 시작 1.5 s 낙상 | 3 | ≤ 1 % |
| YAW/HEADING | 요 표류 °/8 s, 옆 표류 cm | 3 | 요 ≤ 10° |
| COMMAND | 실제 vx 기울기(0.05→0.15) · 전달 체인(명령→클록→유효 cadence→스윙 이동→vx) | 3 | 기울기 ≥ 0.3 이면 '속도 추종 확보', 아니면 미해결 |
| WALK PUSH | 걷기 중 앞 램프 8 N · 뒤 18 N · 옆 15 N | 3 | 기준선(W2-8) 대비 비퇴보 |
| HIP-ZERO | 힙 −3/−1.5/0° (배포 범위) | 3 | 걷기 구간 낙상 ≤ 5 % |
| DELAY | 지연 1·3·4 | — | 지연 4 낙상 ≤ 10 % |

## 판정
- 회복 후보: A 전 항목 비퇴보 + SIGNAL 통과 → 실물 후보. SIGNAL 실패면 NOT READY(신호 필터 후 재평가).
- 보행 후보: B 의 WALK·전환·HIP 통과 → 실물 '걷기 시험' 후보. COMMAND·WALK PUSH 미달은 '미해결'로 명시하되 실물 첫 시험 범위에서 제외 가능.

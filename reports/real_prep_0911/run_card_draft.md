# 실물 실행 카드 (초안 v1 — 2026-09-11) · 후보: v5 + 정정 배포체인 + 리뉴얼 콘솔

목표: 매달림 → 착지 → 지지 제거 → **외부 보조 없이 5 s 자립**(이후 30 s). 판정은 운영자 "모든 줄 느슨·무보조 확인" 이후 콘솔 관측 타이머 + 영상. 발력%·CoP 로 진행·성공을 판정하지 않는다.

## 0. 사전 (승윤님)
- [ ] 모터 전원 ON → 콘솔 `영점 확인 12/12`. 불일치면 **배수 보정 우선**, 영점 재캡처 금지(zero_anchor 규칙).
- [ ] 하드웨어맵 로컬↔젯슨 일치 확인(오늘 stand_zero 12개가 바뀜 — 현장 확인 항목). 갱신했다면 stage8 재기동.
- [ ] 콘솔 `CAN 준비` → `센서 기동`(IMU·접촉 신선) → `선택 정책 = stand_hang_v5` → `브리지 셀프테스트` ALL PASS(인계 워밍업 항목 포함).
- [ ] 시험 방식 = **접지 후 정책 인계**(공중 시작 아님). `행잉 ARM` 미체크.
- [ ] `기록 시작`(첫 제어 조작 전). 영상 촬영 시작(발·줄·후크가 보이게).

## 1. 자세 유지 (콘솔 순서대로, 서버가 실제 응답으로 완료 판정)
1. `stage8 선기동` (인수 대기) → 2. `hang_stand` (에어 유지) → 3. `게인 램프 kp150` — 최대 오차 < 0.3° 확인.
4. 후크를 **CoM 연직**에 맞추고(좌우 편심 최소), 아주 천천히 내려 **양발 접촉**이 콘솔에 뜨면 `▼ 착지` 기록.

## 2. 인계 → 정책
5. `접지 선언` → 6. `핸드오프`(hang_stand 종료·stage8 인수 홀드 12/12 확인) → 7. `기준점 12/12` → 8. `ARM` → 9. `브리지 live` — 콘솔에 **선택 = 로드 = stand_hang_v5** 표시 확인.
10. `stand 발사`. 브리지 로그에 **"인계 워밍업 완료 — 정책 구동 시작"** 이 뜰 때까지(최대 4 s) **줄을 건드리지 않는다**.
   - `sensor_stale_warmup_timeout` 이 뜨면: 방출 금지, stage8 status 스트림/CAN 확인 후 `ARM` → `stand` 재요청.
   - `sensor_stale` 정지가 반복되면 시험 중단(계약 문제).

## 3. 지지 제거 (승윤님 물리 조작, 무개입 원칙)
11. `▶ 방출 시작` 기록 → **좌우 대칭·저속·저크 없이** 줄을 푼다. 콘솔 **좌/우 기울기**를 본다.
12. 좌우 기울기가 3° 를 넘어 커지거나 한 발이 눈에 띄게 뜨면 `⏸ 방출 정지` → 필요 시 `↥ 재인장`(이 시도는 무효로 기록됨). 가드 정지가 뜨면 즉시 회수.
13. 줄이 완전히 느슨하고 손·장치 보조가 없음을 확인한 순간 **`✓ 모든 줄 느슨·무보조 확인`** — 관측 타이머 시작.

## 4. 자립 관측
14. 손대지 않는다. 5 s → 30 s 관측 표시를 본다. 넘어질 조짐(전후 ±10°, 좌우 ±8° 접근)이면 회수 우선(낙상 방지가 기록보다 우선).
15. 결과 구분: 정책 시작 성공 / 부분지지 유지 / **무보조 자립 5 s** / 30 s. 영상으로 줄 상태·무보조 재검토 후 확정.

## 5. 회수 (순서 엄수)
16. `↥ 재인장`(줄로 지지 확인 `support_confirm`) → 17. `스택 종료` → 18. **그 다음에만** `릴리즈`(굽힌 관절 급해제 금지) → 19. `기록 종료` → `이 시험 로그 분석`.

## 즉시 중단
- 전후 기울기 게이트 초과 / 발진 / 가드 정지 / 센서 stale 반복 / 줄이 몸을 옆으로 당기는 느낌.
- 손 보조·재인장 후에는 반드시 `새 시험 준비`로 시도를 구분한다.

## 이번 시험에서 반드시 남길 기록(가설 판별용)
▼착지·▶방출·⏸정지·↥재인장·✓느슨 타임스탬프, 브리지 블랙박스, 패드 원값, stiffness 로그, 영상(발·줄·후크). 이 조합이 없으면 "왜 접촉을 잃었는가"를 또 판별할 수 없다.

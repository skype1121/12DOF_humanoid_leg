# 실물 측정/시험 — 준비 완료 상태 & 남은 순서 (2026-09-11)

## 목표 (수정된 진단 반영)
정책 v5 로 매달림→착지→하중이전→자립. **1차 목표 = 발력%별 앞뒤 CoP+피치 측정**(방향·최대발력·가능성 확정). 그 자체가 성공 시도이기도 함.
- 확정: 62%에서 CoP +8mm(중앙, CoM 벽 아님). 실패 = 방출 중 발끝 앞쏠림(로프가 뒤에서 잡다 풀림).
- 성공 레버(제약 내): 후크 CoM 연직~살짝 앞 정렬 + 매끄러운 미세 방출(저크 금지).

## 남은 순서 (★ = 승윤님 물리 조작)
1. ★ **모터 전원 ON** (지금 12모터 무응답 = 전원 꺼짐).
2. 콘솔 `영점 판정 12/12` — 12/12 확인(불일치면 배수보정 우선).
3. ★ 후크를 **CoM 연직 또는 살짝 앞**으로 정렬(로프가 몸을 뒤에서 잡지 않게).
4. 콘솔 `stage8 선기동` → `hang_stand` → `게인 램프 kp150`(공중 kp150 홀드 확인).
5. 콘솔 `브리지 live`(stand_hang_v5) → `● 기록 시작` → 젯슨 `bash /tmp/start_recorders.sh`.
6. ★ **아주 천천히·매끄럽게 미세 방출**로 착지 → 발력 ~30%에서 잠깐 정지. (저크 금지)
7. 콘솔 `접지 선언` → `핸드오프` → `베이스라인` → ★`ARM` → ★`stand 발사`(행잉 ARM 체크 안 함).
8. 콘솔 운영 이벤트 버튼(▶방출시작/⏸정지/↥재인장/✓슬랙완료)으로 각 조작 시각 기록.
9. ★ 방출을 **발력 5%p당 3초 이상, 매끄럽게** 올림. fwd 가 급격히 +로 튀거나 발끝만 남으면(뒤꿈치 들림) 즉시 정지·재인장.
10. 성공 = 줄 완전 슬랙 + 발력 ≥88%(붙인패드 보정) + 5s + 무개입. 안 되면 최대 지속 발력%에서 멈춰 CoP 데이터 확보.

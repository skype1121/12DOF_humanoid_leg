## 1c. 창 없는 전환 — "ge 0 인 동안은 KE, 걷는 동안만 W3" (사전 등록 1007 17:05, 실행 전)
- 동기(측정): hot-swap 은 restart 와 낙상·과도가 같고(§5.2·§5.3), 수동 홀드 창은 최약 상태(§5.5), W3 STAND 는 KE 보다 밀기에 약하다(12.3 vs 1.7 %). 전환을 gait 래치에 묶으면 창이 없어진다:
  KE →(step 켜기 수락 틱)→ W3 걷기 →(stop 요청 → 반주기 경계 ge 0 래치 틱)→ KE. 정착 추정기·W3 STAND 구간이 필요 없다(배포 구현 = W3 세션의 '서기 정책'을 KE 로 바꾼 합성 러너).
- **X1 KE → W3 즉시 켜기**: `--dir ke2w3 --ke_mode reset|direct --pre_both_s 0 --pre_w_s 0` — KE 서기 4 s → W3 로 전환한 **같은 틱에 gait 켬**(W3 STAND 구간 0). nd, 지연 2, seed 1–3.
  W3 학습 에피소드의 70 % 가 fresh 상태(이력 백필·last_action 0)에서 바로 STEP 으로 시작하므로 reset 방식은 학습 분포 안이라는 가설.
  통과(사전): 전환 뒤 5 s 낙상 ≤ 1 % ∧ 켜기 뒤 1 s 안 첫 이륙 ≥ 95 %(왼발) ∧ 켜기 뒤 5 s 낙상 ≤ 3 % ∧ §5.3(STAND 0.98 s 경유) 대비 걷기 구간 낙상 짝 차 ≤ +3 env.
- **X2 W3 → 래치 즉시 KE**: `--ke_mode reset --settle fixed --settle_s 0` — stop 요청 → ge 0 래치 **그 틱에 KE**(정착 대기 0). nd·b18(16 s)·sf15(16 s), 지연 2, seed 1–3(8 위상 분산 유지).
  래치 순간은 마지막 걸음의 운동량이 남아 있어 KE 감지기가 켜질 수 있다 — 이것은 오탐이 아니라 KE 가 정지 과도를 받는 것이므로 켜짐 비율은 보고만 한다.
  통과(사전): KE 뒤 5 s 낙상 ≤ 1 %(Wilson 상한 < 3 %) ∧ 정상 자세 복귀 중앙 ≤ 3 s·5 s 안 ≥ 90 % ∧ b18·sf15 낙상이 restart(§5.1) 대비 짝 McNemar 에서 유의하게 나쁘지 않고 차 ≤ +3 %p.
- **배포 계약 정합(1007 17:25, 해당 실행 전 추가)**: 합성 러너는 러너를 새로 시작(reset)해 전환한다. (i) W3 쪽 fresh 시작은 클록 게이트가 즉시 1·위상이 2 틱 고정이다(학습 에피소드 시작과 같은 수열) —
  위 X1 은 에피소드 중 0→1(게이트 0.2 s 램프) 경로이므로, fresh 를 모사한 **X1f**(`--w3_fresh`, reset, seed 1–3)를 더한다. X1 판정은 X1f(배포와 같은 수열)로 하고 X1(램프)은 변종 대조로 보고한다.
  (ii) KE 쪽은 W3 가 래치 틱을 처리하고 **다음 틱부터** KE 다 → X2 는 `--settle_s 0.02`(1 틱)로 실행한다.
- **X2d(1007 17:45 등록, 실행 전) — 래치 다음 틱 KE, 상태 이어받기(direct)**: X2(reset) seed 1 무외란이 KE 뒤 2 s 낙상 14/106 으로 기준을 크게 벗어났다(§5.6). 원인 대조(측정):
  낙상 env 는 전부 `base_too_low`(쓰러짐이 아니라 주저앉음)·행동 폭주(|a| 수백–수천, 직전 액션 관측 자기 되먹임). 기록 관측을 내보낸 정책에 넣으면 폭주가 그대로 재현되고(회복 36.8·서기 95.1),

## 3. 판정 규칙(사전 고정)
- **R1 restart 무해(Q1)**: nd·지연 2·seed 1–3 합(≈ 300 env): 전환 뒤 5 s 안 낙상 ≤ 1 %(Wilson 상한 < 3 %) ∧ KE 감지기 오탐(외란 없는데 켜짐) ≤ 5 %(홀드→KE nd 오탐 3.2 % + 여유) ∧ 정상 자세 복귀 중앙 ≤ 3 s·5 s 안 ≥ 90 %.
- **R2 과도(Q1)**: 전환 뒤 2 s 피크 |피치|·|롤| 중앙 ≤ none 팔 같은 창 + 2°, 피크 |ω_xy| 중앙 ≤ 0.5·p95 ≤ 1.0 rad/s. 관절 목표 틱당 변화는 슬루(4°/틱)로 묶여 있어 보고만.
- **R3 외란 내성(Q3)**: b18·sf15(14 s)·지연 2·seed 1–3: restart 낙상 ≤ 홀드→KE 기준선(sab_imu seed 1–6, 지연 2: b18 5.9 %·sf15 18.3 %) + 5 %p ∧ none 보다 ≥ 5 %p 낮고 Fisher p < 0.05(b18 기준; sf15 는 방향 일치).
- **R4 방식 비교(Q2)**: 같은 seed·env 짝에서 direct·reset 이 restart 보다 전환 뒤 5 s 낙상(nd+b18+sf15 합)이 적고 차이 ≥ 3 env·McNemar p < 0.05 → "hot-swap 이득 있음(별도 개발 가치)"; 아니면 restart 유지. direct 가 restart 보다 ≥ 3 %p 많으면 "상태 이어받기 위험" 기록.
- **R5 STOP 경유(Q2)**: nostop 전환 뒤 5 s 낙상 ≥ restart + 5 %p(p < 0.05) → "STOP 경유 유리" 확인. 반대면 보고(STOP 이 손해).
- **R6 지연**: 지연 3·4 에서 R1·R3 재보고(퇴보 폭). 정착 상한 3 s 초과 비율 보고.
- **Q4**: 탐색 — 낙상률 3 팔 보고, 결론 없음(n 작음). 기존 '밀린 뒤 stop 이 더 위험' 결과와 방향 비교만.
- **Q5(탐색, 지시 6 — 학습 없음, 1007 16:20 등록, 실행 전)**: 걷는 중 외란 직후 'WALK → DISTURBANCE → RECOVERY(KE) → STAND' 체인이 기존 정책만으로 성립하는지 첫 측정.

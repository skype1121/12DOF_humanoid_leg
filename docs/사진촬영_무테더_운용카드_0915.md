# 사진 촬영·무테더(인터넷 없음) 운용 카드 — 0915

## 연결
- **USB 와이파이 동글(Realtek RTL8811CU, 0bda:c811)을 젯슨에 꽂아 둔다.** 내장 와이파이(RTL8822CE)는 안테나가 없어 신호가 거의 안 나가므로 쓰지 않는다(스캔 시험 0915: 주변 AP 27%/0%). 동글 드라이버 `8821cu`(morrownr/8821cu-20210916, 젯슨에서 빌드·설치, 부팅 시 자동 로드)는 젯슨 `/lib/modules/5.15.185-tegra/kernel/drivers/net/wireless/8821cu.ko`. 핫스팟 프로필은 동글 인터페이스 `wlx40a5ef589d99` 에 고정.
- 젯슨 이름으로도 접속됨: `ssh mama@ubuntu.local` (avahi mDNS, docker/tailscale 주소 제외).
- 젯슨 전원 ON → 약 1분 뒤 **핫스팟 자동**: SSID `HUMANOID-JETSON` / 비번 `***` / 젯슨 IP **10.42.0.1** (고정, 부팅 자동)
- 노트북·폰을 그 와이파이에 붙인 뒤
  - 터미널: `ssh mama@10.42.0.1` (비번 ***) → `robotctl ...`
  - 또는 브라우저: `http://10.42.0.1:8800` (콘솔 그대로, 설정·점검 탭에 개별 제어기·에어 보행·kd·영점 배수 보정 버튼)
- 콘솔 서비스는 부팅 시 자동(`operator-console.service`). 안 뜨면: `sudo systemctl restart operator-console.service`

## 순서 (ssh)
```
robotctl status          # 상태 한 줄 (watch = 1초마다)
robotctl prep            # CAN → 센서 → 영점 확인 → 계약 검사 → 인수 제어기 (완료 단계 건너뜀)
robotctl zero-fix        # 영점 확인이 '창 어긋남'이면(전원 재투입 뒤 흔함) → 배수 보정 → 다시 prep
robotctl hang            # 공중 자세 유지 → 운용 게인 kp150   ※ 줄이 로봇 지지·다리 주변 사람 없음
robotctl level           # 수평 기준 자세(힙앞뒤 ±20.5·무릎 ±30·발목앞뒤 ±19) — 사진용 정지 자세
robotctl walk            # 공중 제자리걸음 0.5 Hz (힙 20·무릎 30·발목 8°, 2 s 페이드인) — 발이 바닥에서 떨어져 있어야 켜짐
robotctl walk --f 0.7 --hip 25 --knee 35   # 속도·진폭 조절 (f 0.2~1.0, 힙≤30, 무릎≤45, 발목≤15)
robotctl stop            # 보행 정지(자세 유지)
robotctl zero            # 보행 정지 + 개별 조정 0 = 매달림 기준(제로) 자세
robotctl kd 10           # 홀드 감쇠(출렁임 줄이기, 1~30, 기본 5)
robotctl trim left_knee -25   # 관절 하나 개별 조정
robotctl ground          # 발을 바닥에 대고 서게 할 때만(접지 선언) — 접지 뒤엔 walk 거부됨
robotctl down            # 회수: 줄 지지 확인 → 제어 종료 → 토크 해제
robotctl new             # 새 시험
robotctl estop           # 정지 요청
```
`-y` 를 붙이면 확인 질문 생략(`hang -y`, `walk -y`, `down -y`).

## 안전
- 모든 명령은 콘솔 서버 게이트를 그대로 통과한다(순서·선행조건·확인). walk 는 **접지 선언·발 접촉이 있으면 서버가 거부**.
- 회수 순서(줄 인장 → 제어 종료 → 토크 해제)는 `down` 이 그대로 지킨다. 보행 중이면 먼저 `stop`.
- 핫스팟 비번을 아는 사람은 8800 콘솔로 모터를 움직일 수 있다. 촬영 뒤 필요하면 `nmcli con down humanoid-ap`.
- 왼발 감압 센서 1개 탈락(0914) — 접촉 비트는 참고만.

## 구현 메모
- 에어 보행: `hang_stand.py` 가 `/tmp/air_gait.json` 을 읽어 kp150·미접지에서만 관절 프레임 패턴(왼/오른 위상 π 차, sin² 들어올림)을 개별 조정에 합산, 좌우 대칭 소프트 한계로 클램프, 2 s 페이드. 정지 시 위상 0 복귀. 상태 파일 `/tmp/hang_stand_status.json` 의 `gait`.
- CLI: `jetson/scripts/robotctl.py` (`~/bin/robotctl`), 콘솔 `/api/state`·`/api/action` 사용.
- 핫스팟: NetworkManager 프로필 `humanoid-ap`(wlP1p1s0, AP, ch6, ipv4 shared 10.42.0.1/24, autoconnect, WPA2-PSK). `dnsmasq-base` 반설치 상태를 `dpkg --configure` 로 마무리함.

# 최종 WALK/TURN 후보 선정 규칙 (사전 등록 v1, 2026-10-07 22:56, claude2 — S3g·S3t·S3tD 결과를 보기 전)

기준선 = **W3S3d-15800**(현재 배포 대상, 키 `stand_w3s3d_15800`). 이 문서는 오늘 밤 여러 단일 변경 학습이 끝난 뒤 "무엇을 최종 후보로 부를지"를 미리 정한다.
결과를 본 뒤 규칙을 바꾸지 않는다. 통과 후보가 없으면 기준선을 유지한다(학습 횟수·버전 증가는 진척이 아니다).

## 1. 단일 변경 팔(전부 W3S3d-15800 에서 +500, 후보 체크포인트 16100·16299, 관측·행동 계약 불변)
| 팔 | 단일 변경 | 겨냥 | 기전 기준(사전 등록 위치) | 상태 |
|---|---|---|---|---|
| W3S3e | 명령 리샘플 8–12 → 4–6 s | 재출발 | E1 ∧ E2 (`S3E_DESIGN.md` §4) | 판정 끝: 후보 없음 |
| W3S3f | 토크 한계 무작위화 0.7–1.0 | 낮은 한계에서 버팀 | F1 ∧ F2 (`TORQUE_BUDGET_1007.md` §7) | 평가 중 |
| W3S3g | W3S3e + 주기 평균 옆 기울기 선형 벌점 | 쏠린 걸음(요 누적) | G1 ∧ G2 (`TRANSITION_W3KE.md` §5.19) | 학습 중 |

## 2. 묶음 후보 W3S3x 를 만들 조건
- 넣는 변경 = 자기 팔에서 **기전 기준을 채우고**, 해치지 않음(토크 한계 1.0 배 걷기 낙상 ≤ 2 % ∧ 앞 0.06 의 8 s 전진 중앙 ≥ 0.53 m — 기준선 0.62 m 의 0.85 배)도 채운 것만.
  기전은 채웠지만 전진이 미달인 변경은 묶음에 넣되, 묶음의 판정에서 전진 기준을 다시 본다(전진 미달이 다른 변경과 합쳐 풀리는지는 미리 알 수 없다 — 넣는 근거는 기전 충족뿐).
- 채운 변경이 하나도 없으면 묶음을 만들지 않는다. 채운 변경이 하나뿐이면 그 팔의 체크포인트가 곧 후보다(묶음 학습 생략).
- 학습: W3S3d-15800 에서 +1000(후보 +500·+1000), seed 1, 4096 env. 가중·범위는 각 팔의 값을 그대로 쓴다(묶음에서 다시 조정하지 않는다).

## 3. 최종 후보 판정(묶음이든 단일 팔이든 같은 기준, 전부 배포 코드 폐루프·256 env·seed 1–2 — E4·E6 은 정책 직접 평가)
| # | 평가 | 기준 |
|---|---|---|
| S1 왕복(X7 대본: 앞·회전·옆·뒤·앞) | `S3E_DESIGN.md` E3 | X7 등록 기준 ①–④ 전부(② 48 s 낙상 ≤ 5 % — 기준선은 7.4 % 로 미달) |
| S2 단일 걷기 회귀 | E4 | 명령별 낙상 +2 %p 이하 ∧ 속도·회전 추종 이득 ≥ 기준선의 0.85 배 |
| S3 전환 회귀 | E5 | KE 인계 뒤·외란 뒤 낙상이 X6b 대비 +3 %p 이하 |
| S4 걷는 중 외란 | E6 | 방향·크기별 낙상 +5 %p 이하 |
| S5 콘솔 버튼 대본(X14) | `TRANSITION_W3KE.md` §5.18 | B1·B2·B3 충족 ∧ 기준선에서 통과한 버튼 6 개의 방향 부호 일치 ≥ 95 % 유지 |
| S6 겨냥한 개선이 실제로 있음 | 넣은 변경의 기전 기준 | 묶음에 넣은 변경마다 자기 기전 기준을 묶음 정책에서 다시 채울 것(하나라도 미달이면 그 개선은 "없음"으로 보고) |
- **승격** = S1–S5 전부 충족 ∧ S6 에서 적어도 하나의 개선이 남음. 후보가 둘이면 S1 의 48 s 낙상이 낮은 쪽, 같으면 이른 체크포인트.
- S1 만 미달이고 S2–S5 가 충족이면 "부분 개선"으로 기록하고 기준선을 유지한다(왕복 낙상이 기준선보다 유의하게 낮아도 5 % 문턱을 넘으면 승격하지 않는다).
- 승격되면: 내보내기(policy.onnx/pt)·md5 기록 → 브리지 키 추가는 **실험 플래그 뒤**(기존 키 불변) → 젯슨 배포 묶음에 포함 → 로컬 torch 대 젯슨 onnx 러너 동치 확인(`jetson_parity.py`).
  실물에서 쓸지는 사용자가 정한다. 시뮬 통과는 실물 성공을 뜻하지 않는다.

## 4. 한계(미리 적음)
- 학습 seed 1 개. 체크포인트 간 변동이 크다는 것을 W3S3e 에서 봤다(낙상 0.65 % ↔ 1.32 %). 승격 후보는 평가 seed 를 3 으로 늘려 S1 을 한 번 더 본다(같은 기준).
- 토크: 시뮬 한계는 관절 토크를 자르는 것이고 실물의 전원 처짐·열 누적이 아니다. 걷는 중 RMS 가 연속 정격(8.3 N·m)보다 높으면 "짧은 시연만 가능"으로 적는다.

## 원칙
- 문턱 = **현재 기준선 값 ± 허용폭**. 기준선은 이미 잰 실행(출처 태그 = `log_picture/` 파일)에서 가져왔다. 허용폭은 seed 간 변동(KE: 같은 인자 seed 1–6 낙상 17–27 % 범위,
  LOG 1006 'KE fi40 v1/v2 6 seed')과 표본 수를 덮도록 잡았다. 시뮬 판정이며 **실물 성공 확률이 아니다**.
- 횟수 지표(`비율≤`·`비율≥`)는 Wilson 95 % 구간으로 3 단계: 점추정이 문턱 안 = PASS, 밖이지만 구간이 문턱을 걸침 = **경계**(빠른 모드 표본 부족 → 전체 모드로 재확인), 구간 전체가 밖 = FAIL.
  연속 지표(`≤`·`≥`·`구간`·`|x|≤`)는 문턱 밖 = FAIL. 짝 지표(`짝`)는 같은 (seed, env) McNemar — 후보 쪽 낙상이 많고 p < 0.05 = FAIL, 많지만 p ≥ 0.05 = 경계.
- **기준선 env 짝(K-ref)**: KE 는 `settle_ab_run.sh` 와 인자가 같아 같은 seed 면 기준선 `sab_imu`·`sab_odicw` 와 RNG 경로가 같다(kabs3 ≡ sab_imu 전 셀 일치 확인, 1007).
  개선이 환경·관측·KE 코드를 바꾸면 짝 결과가 그 효과를 직접 보여 준다(RNG 지문이 깨지면 '짝 불가'로 표시 — 그 자체가 환경 변경 신호).
- 빠른 모드는 seed 1·env 축소라 기준선(대개 256 env·seed 1, KE 는 6 seed 합)과 같은 표본이 아니다 → 빠른 모드의 '경계'는 실패 확정이 아니다.
- 프로필: `적용 = 혼합` 행은 `--profile s4d`(혼합 명령 학습 후보)에서만 판정, s3d(W3S3d-15800)에서는 참고. `적용 = 전체` 행은 전체 모드에서만 실행.
- 각 W3 항목의 **채점 낙상** 분모 = env − 시작 과도(워밍업 2 s) 낙상(eval_w3 1006 판정 정의). 시작 과도는 `W-z.warm` 에서 따로 본다.

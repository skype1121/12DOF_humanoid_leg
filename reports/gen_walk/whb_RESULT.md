# WHB 결과 (1005, 보행 트랙) — 힙 앞뒤 공유 영점 편향 강건성

W2-8 24791 + G21a 전환, 배포 조건(보조 α1 + HH), 지연 3, seed 1, 그룹 n 100. 낙상 시점 [서기 중 / 걷기 시작 / 걷기 / 정지 뒤].
| 힙 편향 | 서기(착지) 구간 | 걷기 구간 | 정지 뒤 |
|---|---|---|---|
| −4.5° | 0–1 | 1–2 | 2–6 |
| −3.0° | 1–3 | 0 | 0–2 |
| −1.5° | 4–8 | 0 | 0 |
| 0.0° | 19–23 | 0–1 | 0 |
| +1.5° | 38–46 | 0–1 | 0 |
- **보행 정책은 −4.5 ~ +1.5° 전 구간에서 걷기 중 낙상 ≤ 2 %.** 강건하다.
- 약점은 **G21a 서기 착지 구간**이다. 학습 DR(shared_hip_f −3 ~ −1°) 밖 0°에서 18–23 %, +1.5°에서 38–46 %. 보행이 아니라 서기 정책(행잉→착지)의 문제이고, 기존 DX3 힙 편향 민감도와 일치한다.
- **부호 정정(검토 13회차, DX3 규약 left_hip_f − = 신전):** 표의 − 값 = 신전, + 값 = 굴곡이다. 학습 DR −3 ~ −1° = 신전 1–3°.
  큰 신전(−4.5°)에서는 정지 뒤 낙상 2–6 %(걷기→서기 인계 약화). **굴곡 쪽(0 ~ +1.5°)에서 G21a 착지가 무너진다**(DX3 의 굴곡 홀드 악화와 일치).
- 실물 위험: 최근 영점 점검의 '굴곡 ~2.2° 공통'(지그 가정)이 이 규약에서 +2.2°라면 착지 실패 구간이다. 다만 1004 실기에서는 G21a 서기가 정상이었다 → 실물 영점 측정의 프레임·부호가 이 규약과 같은지 먼저 확인해야 한다(미검증).

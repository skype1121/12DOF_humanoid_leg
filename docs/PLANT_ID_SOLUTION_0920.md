## 5. 해법(0920 13:xx 판)
### 5.1 시뮬 플랜트(권장, 가설 표시)
- 무릎: 하중 탄성 처짐 → 상수 편향 −12.6°(±3, 공유) — 정적 근사. 더 충실하게는 직렬 스프링 k≈35~45 Nm/rad(SEA 액추에이터 구현 중).
- 발목앞뒤: 기계 유격 반폭 4° + 쿨롱 마찰 ~2 Nm(DeadzoneCoulombImplicit) — '버티는 구간'을 만드는 최소 모델.
- 힙: −2° (±2).  지면: 강체(연성 k2000 은 기각).
- 관측: 실물 엔코더는 유격 안 움직임을 못 봄 → 엔코더측 관측 항(구현 중) 을 정책 관측에 써야 계약이 맞음.
### 5.2 실물 쪽 개선(하드웨어) — 시뮬 정합보다 효과 클 가능성
- 발목앞뒤 전동부 8° 유격: 백래시/브래킷 휨 점검 후 제거·보강. 유격이 0 에 가까워지면 '착지마다 다른 자세'·'밀기 방향별 강함 차이'가 대부분 사라진다(F4·F6 의 원천).
- 무릎 12° 하중 처짐: 브래킷/클램프 보강. 처짐이 줄면 v5 힙 30°가 아니라 시뮬처럼 힙 ~10°에서 수평이 된다 — 그때 정책 기본자세도 바뀜(재캡처 필요).
### 5.3 절차·콘솔(반영 완료)
- 자동수평: 정착 2 s 뒤에만 적분(밀기 오프셋 누적 해소). 센서 재기동·강제 초기화·종료코드 표·motors 영점 표·재캡처 좌표변환 도구.

# KB 사전 기록 (1005) — 실패 B: 몸통이 뒤로 돌아선 뒤에도 cue(전진 스텝 모드)가 남는가
B 시계열(kr fi40 지연 4, 덤프 64 env): 앞 걸음 착지(+0.6 s) 뒤 피치 +5 → −7~−14°, 속도 +0.4 → −0.3~−1.0 m/s 로 뒤로 넘침.
뒤로 가는 동안 발이 골반 앞(+14~+41 cm)에 있다. 반전은 착지 직후(~2.8–3.0 s)이고 cue 는 켜짐(~2.1 s) 뒤 1 s 까지 남는다.
- 가설 H-B1: 뒤로 돌아선 뒤의 전진 스텝 신호가 B 를 만든다.
- 변수 하나: cue 종료 조건 추가 — 기준 대비 피치 < −2° 또는 IMU ω_y < −0.3 rad/s 이면 즉시 종료(kb2), 또는 피치 < 0°·ω_y < 0(kb0).
- kr 지연 4, seed 1·2, sf15 fs80 fi40 b18 nd, 대조 krd4.
- 판정: fi40·fs80 B(양수 여유 낙상) 감소 + 전체 낙상 비악화(특히 A 증가 여부) + b18·nd 비퇴보 → 채택.

## 1. 구조
```
IMU 기울기·|ω_xy|, 접촉 0/1, 유효 착지 사건 ──► supervisor(c2_core) ──► _ge_cmd ──► W3 엔진(w3_gait_update: 0→1 위상 0, 1→0 반주기 경계 래치)
                                                                         │                 └─► gait_clock 관측(ge 램프 0.2 s), 위상
                                                                         └─ 회복 에피소드 명령 = 0(관측 velocity_commands 채널 그대로)
정책(W3S1c 이어 학습, actor 320 불변) ──► 관절 목표(기존 배포 체인)
보상/critic 전용 특권량: CoM·v_CoM → ICP 오프셋 v/ω0 → 회복 착지 목표, 정착 판정 |v|
```
supervisor 상태기계(배포 가능 신호만, 학습 전용 '무장' 1개):

| 상태 | ge 요청 | 전이 |
|---|---|---|
| STAND(0) | 0 | 감지(기울기 > 4° 또는 \|ω_xy\| > 0.5, **지연 2 틱**) & 무장 & 불응 끝 → REC |
| REC(1) | 1 | ① REC ≥ 0.9 s & 유효 착지 ≥ 1 & 최근 0.45 s max\|ω_xy\| < 0.6 & max 기울기 < 4° (c2v: & \|v̂\| < 0.10) → STOPREQ ② REC ≥ 4 s(시간 초과) → STOPREQ |
| STOPREQ(2) | 0 | 엔진이 반주기 경계에서 실제 ge 0 → POST(불응 0.5 s) / 감지 재발화(시간 초과 아님) → REC 취소 |
| POST(3) | 0 | 3 s 뒤 STAND. 불응 뒤 감지 & 무장 → REC(두 번째 외란·정지 실패 재진입) |

- **무장**(학습 전용): 학습 외력이 걸렸거나 해제 뒤 2.5 s 안. 정책이 흔들어서 스스로 STEP 을 여는 경로(G16a 자기 개방)를 차단. 배포·평가에서는 `C2_ARM=deploy` = 항상 참(무외란 오탐까지 측정).
- 감지 문턱 4°·0.5 rad/s = KE 감지기 `--sw_on` 기본값(배포 검증 이력). **정지 문턱(0.6 rad/s·4°·창 0.45 s)은 가정값** — §4 C2CAL 로 확정.
- 정지 요청은 상태 조건, 정지 시각은 엔진의 반주기 래치(스윙 중 끄지 않음). c2 는 `_ge_cmd` 만 쓰고 W3 래치 코드는 그대로 호출한다.

## 4. 학습 전 단계(순서 고정, 각 단계 통과해야 다음)
### C2CAL — 정지 문턱 실측(학습 없음, GPU 1회, 최고 정보량)
- W3S1c 끝 × `Biped12-HangStand-W3C2-v0` × `C2_ARM=deploy` + 진단 로그: (a) 무외란 제자리 걸음 중 창(0.45 s) max\|ω_xy\|·max 기울기 분포,
  (b) R3 외란 뒤 REC 구간의 같은 분포와 참 \|v\|, (c) 감지 오탐률(무외란 STAND·STEP 각각).
- 확정 규칙(사전): stop_w = (a) 의 p90 × 1.2, stop_tilt = (a) 기울기 p90 + 1°. 단 (b) 에서 \|v\| > 0.15 인 틱의 ≥ 80 % 가 그 문턱을 넘어야 함
  — **넘지 못하면 IMU 만으로 운동량 소멸을 못 가른다는 뜻 → c2v(|v| 추정 조건)가 주 경로로 승격**, c2 는 대조로 내림.
- 오탐: 무외란 STAND 의 감지 켜짐 ≤ 1 %/에피소드(KE 기준 nd 채터 ≤ 0.7 %). 넘으면 무장 없는 배포에서 STEP 이 남발됨 → 감지 문턱/필터를 먼저 고침.

### C2UNIT — 반사실 보상 단위시험(reward_landscape 방식: 행동 궤적 × 보상 조건, 학습 없음)
같은 정책(W3S1c 끝)·같은 외란 seed·같은 env 로 **행동 팔**을 supervisor 덮어쓰기로 만들고, 각 궤적을 **보상 조건** 여럿으로 채점한다.

행동 팔(env var, 코드에 구현됨):
| 팔 | 설정 | 의미 |
|---|---|---|
| B1 STAND | `C2_ARM=stand` | 회복 켜짐 금지(발목 전략만, ge 0) |
| B2 NOSTOP | `C2_PARAMS=min_td=1e6,tmax_s=1e9` | 켜지고 멈추지 않음(RW3Z 형) |
| B3 C2 | 기본 | 상태 조건 정지 |
| B4 EARLY | `C2_PARAMS=min_rec_s=0,stop_w=1e9,stop_tilt=1e9` | 첫 유효 착지 직후 정지(너무 이름) |
| B5 LATE | `C2_PARAMS=min_td=1e6` | 시간 초과(4 s)로만 정지 |
| B6 CUE | B3 + **actor 관측만** velocity_commands 를 REC 동안 vx = ±0.06(외력 방향, 특권) — 보상·env 명령은 0 | 밀린 방향으로 딛는 궤적의 대리(W3S1c 는 명령 → 보폭 기울기 정상) |

보상 조건: R0 = W3S1c 보상(현행), R1 = c2 전체, R1a = c2 − 포획 착지(명목 착지로), R1b = c2 − 정착 보너스.
외란 조건: sf15(램프 15 N 0.5/1.0 s), fi40(40 N·0.2 s), b18(뒤 18 N·0.3 s), nd. seed 1·2, 팔당 256 env, 외란 뒤 8 s 창.
지표(항별 raw·초당 기여·사건 빈도·회복 1건당 합, 낙상 env 분리): `c2_place`, `c2_settle`, W3 STEP 항, STAND 항, 종료 벌점.

통과 기준(사전, 모두 충족해야 C2 학습 시작):
1. **불변**: nd 와 무외란 범주 env 에서 R1 의 항별 합 = R0(차 ≤ 1e-6/에피소드) — 코드 수준은 CPU 7e·7f·6e·4f 로 확인됨, 여기서는 env 안에서 재확인.
2. **포획 배치가 이긴다**: 생존 env 회복 착지 1회당 `c2_place` 평균 B6 > B3 ≥ B2 이고 B6 − B2 ≥ +0.15(가중 적용 뒤 사건당). R0 에서는 B6 ≤ B2(현행 보상이 포획 배치를 벌한다는 진단 — 기대이며 불합격 사유 아님, 기록).
3. **멈추는 것이 이긴다**: 외란 뒤 8 s 회복 1건당 R1 총합 B3 > B5 > B2, B3 − B2 ≥ +1.0. R1b(정착 없음)에서도 B3 ≥ B2 면 정착 보너스 없이도 정지 동기가 있다는 뜻 → 정착 가중 50 은 유지·기록.
4. **파밍 없음**: 모든 팔에서 외란 1건당 `c2_settle` ≤ 1, 무외란 env 켜짐 0(무장), B1 의 c2 항 = 0.
5. **너무 이른 정지가 이기지 않는다**: B4 의 R1 총합 ≤ B3(같은 seed 짝 비교). B4 > B3 이면 min_rec_s·창이 보상 구조상 무의미 → 정지 조건 재설계.
- Kill(c2 보상 설계 폐기): 기준 2·3 이 둘 다 FAIL(포획도 정지도 보상 지형에서 이기지 못함).

### C2 학습(사전 등록 초안 — 실행 승인·GPU 확보 뒤)
- W3S1c 끝 → `Biped12-HangStand-W3C2-v0` `--resume` +500 / +1000, seed 1·2. 평가 체크포인트 +250 단위(저장 간격 100 정합).
- 평가(보조 0, `C2_ARM=deploy`, 지연 2·3, 256 env × seed 1·2): nd·sf15·fs80·fi40·b18 = KE 와 같은 조건.
  **평가 어댑터 필요(미구현)**: eval_ground_recovery 는 정책 전환형이라 W3 위상·ge 를 모른다 → W3C2 env 를 그대로 쓰는 c2 평가 모드(`env._c2_enable` 으로 홀드 구간 켜짐 금지 — 훅은 구현됨) + CLOSE2 계측(cue/REC 뒤 이륙, 표류, 정착 시간, 끝 자세) 이식.
- 성공(사전): 엄격 성공(S5 없음 = 정지 요청 뒤 이륙 ≤ 1 & 표류 ≤ 5 cm, 정착 ≤ 2 s, 자세 복귀) sf15·fi40 에서 KE 대비 +10 %p(p < 0.05),
  낙상 sf15·fi40·fs80 ≤ KE + 3 %p, b18 ≤ KE + 3 %p, nd 낙상 ≤ 0.5 %·nd 켜짐(오탐) ≤ 1 %, 무외란 W3 회귀 없음(제자리 교대 ≥ 95 %·명령 0 영점 |vx| ≤ 0.01·앞/뒤 vx 유지).
- Kill: +500 에서 sf15 낙상 > KE + 15 %p 이고 2 보 포획 여유 중앙 < KE − 5 cm(포획 배치 미획득) → c2 보상 경로 중단, 대안(§6) 으로.
- 해킹 감시: REC 점유율(`c2_rec_frac`)·시간 초과 비율(`c2_timeout/c2_trig`)·취소 비율 — 시간 초과 > 30 % 면 정지 조건이 학습된 걸음 흔들림을 못 넘는 것.

## 6. 변형·대안
- c2v(`W3C2v`): 정지 요청에 \|v̂\| < 0.10(학습 = 참 몸통 속도 + σ 0.03). C2CAL 이 IMU 만으로 운동량 소멸을 못 가르면 주 경로. 배포 선행 조건 = 다리 운동학 속도 추정기(지지발 고정 가정, 발목 유격이 위치보다 속도에 덜 민감 — 가설).
- c2i(`W3C2i`): critic 에 ICP. 가치 추정이 포획 상황을 못 가를 때만(critic 은 이미 base_lin_vel 5 프레임을 봄 → 기본은 끔).

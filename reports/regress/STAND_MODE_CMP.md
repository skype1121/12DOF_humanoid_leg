하네스 = `eval_ground_recovery.py` G11a 128 env, 홀드 사전검사 3 s → 정책 인계(블렌딩 1.5 s) → 8 s, 접촉 관측 v2, 지연 2(과도 시험은 3·4),
`--last_action_ema 0.27 --obs_ema joint_vel:0.25`, DR 켬. 분모 = 사전검사 통과 env(홀드는 정책 이전이라 세 팔 공통).
- **(a) W3**: `--load_run 2026-10-07_00-11-12_w3S3d_from_s2d --checkpoint model_15800.pt --c2 --c2_arm ge0` — c2 평가 어댑터의 W3 위상·ge 래치를 쓰되
  새 팔 `ge0` = 전 env ge 0·명령 0 고정, 회복 켜짐 금지(supervisor 무장 안 함). = 실물 T1 의 `{"cmd":"stand"}`(W3 정책 ge 0) 와 같은 의미.
  코드 변경: `w3_c2.py` `C2_ARM=ge0`(→ `_c2_arm_off`·전 env 마스크), `eval_ground_recovery --c2_arm` 선택지 추가. 기존 팔(stand·deploy·march) 동작 불변.

## 지표(env 별, 사전검사 통과 env)
- 낙상 `fell` · 끝 정상 자세(회귀 summarize `posture_ok`: 외란 = nrm_t 있음 ∧ abn ≤ 0.1 ∧ 양발, nd = 끝 수평 < 3°·명목 관절 < 5°·양발)
- 스텝 발생 `takeoffs > 0`(발 들기 ≥ 1)
- 인계 과도 낙상 = 낙상 ∧ `t_fall_rel` < 2.0 s(인계 직후, 외란 전 — nd 에서는 낙상 전부가 대상인지 함께 보고)
- 보조: 최종 정숙 `final_quiet`, KE 회복 모드 사용(`sw_on_n`), W3 팔의 `sw_on_n` = 0 확인(ge0 팔이 실제로 회복을 켜지 않았는지 — 0 아니면 팔 무효)

## 통계
- 짝: 같은 (seed, env) 이고 RNG 지문(bias_*·com_*·pre_pass·pre_pitch)이 같을 때 McNemar. 지문이 다르면(어댑터 이벤트가 난수를 더 소비할 수 있음) 비짝 Fisher 정확 검정(양측)으로 대체하고 그렇게 표기.
- 다중 비교: 조건 5 × 비교 2 = 10 → 개별 p 는 보고만, 결론은 아래 규칙.

## 판정 규칙(사전 고정)
- **Q1 'W3 STAND 모드가 더 위험'** = 아래 중 하나:
  (i) 외란 4 조건 합 낙상이 G21a 대비 +3 %p 이상이고 p < 0.05, 또는 (ii) 어느 한 외란 조건에서 G21a 대비 +5 %p 이상이고 p < 0.005(≈ 0.05/10),
  또는 (iii) 인계 과도 낙상(nd, 지연 2·3·4 합)이 G21a 대비 +2 %p 이상이고 p < 0.05, 또는 (iv) nd 끝 정상 자세가 G21a 대비 −5 %p 이상이고 p < 0.05.
  KE 대비도 같은 규칙으로 따로 판정. 반대 방향(W3 가 유의하게 낫다)도 같은 문턱으로 '더 안전'.
  어느 쪽도 아니면 '구별 안 됨(이 표본에서)'.
- **Q2 '걷기 정지 뒤 KE 인계 권장'** = KE 가 W3 STAND 모드보다 외란 4 조건 합 낙상이 −5 %p 이상 낮고 p < 0.05 이면서, KE 의 nd 낙상·인계 과도 낙상이 W3 보다 유의하게(+2 %p, p < 0.05) 나쁘지 않음.
  주의(한계, 결론에 반드시 명시): 이 시험은 **홀드 → 정책 인계**에서 시작한다. 실제 W3 걷기 정지 → KE(G21a) 전환 과도(W3 행동 이력·위상에서 G21a 로 넘어가는 순간)는 재지 않는다
  → Q2 가 '권장'이어도 W3→G21a 인계 과도 시험(별도)을 통과해야 배포 반영. 시뮬 판정이며 실물 성공 확률이 아니다.
